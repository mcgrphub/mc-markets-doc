This quickstart walks you through your first MC OpenAPI call: create an API Key, sign the request with **HMAC-SHA256**, and call the exchange-rate endpoint through the gateway.

<Note>
  You need an MC platform account before you begin. If you don't have one, contact your MC representative. Every request needs a new `X-Nonce` (**UUID v4**, or ≥32 hex characters).
</Note>

<Steps>
  <Step title="Create an API Key">
    After signing in to the MC platform, open [User Center](https://www.mcmarkets.com/zh-Hans/uc/user-info), or select **User Center** from the account menu in the upper-right corner. In the **API Key** section, click **Create API**. Complete identity verification first if the page requires it.

    <Frame>
      ![Open the API Key section from User Center and click Create API](/images/guides/mcp/create-api-entry.png)
    </Frame>

    Enter an API name and select the permissions you need:

    - `READ` — read-only operations (balances, lists, queries)
    - `TRADE` — trading operations (place / cancel orders)
    - `WITHDRAW` — withdrawal and transfer operations

    Select the `TRADE` permission to use MCP for flash conversion, deposits, withdrawals, order placement, order modification, position closing, or order cancellation.

    Configure an IP whitelist if needed (up to 15 IPv4 addresses, separated by commas).

    <Frame>
      ![Enter an API name and configure permissions and an IP whitelist](/images/guides/mcp/create-api-form.png)
    </Frame>

    Click **Confirm**. If two-factor verification is enabled for your business line, complete the GA and email verification prompts. After the key is created, immediately copy and securely store the **Access Key** and **Secret Key** — the Secret Key is shown only once.

    <Warning>
      Never commit the Secret Key to source control, and never expose it in client-side code.
    </Warning>
  </Step>
  <Step title="Sign a request">
    Every authenticated request needs at least four headers:

    | Header | Value |
    | --- | --- |
    | `X-Access-Key` | Your Access Key |
    | `X-Timestamp` | Current Unix time in **milliseconds** (within ±10 minutes of server time) |
    | `X-Nonce` | New value per request; **UUID v4**, or ≥32 hex characters (`0-9a-fA-F`) |
    | `X-Signature` | **Base64**-encoded HMAC-SHA256 of the string to sign |

    Build the string to sign by joining the following parts with `\n`, then append a trailing `\n`:

    ```text
    {HTTP_METHOD}
    {REQUEST_URI}
    {QUERY_STRING}       # omit entire line if no query (do not insert a blank line)
    {SIGNED_HEADERS}     # x-access-key, x-nonce, x-timestamp — lowercase keys, sorted
    {TIMESTAMP}
    {NONCE}
    [{BODY_SHA256_HEX}]  # for non-empty POST/PUT/PATCH/DELETE bodies
    ```

    See [Authentication](/authentication) for the full rules and Python / Java / Node.js samples.
  </Step>
  <Step title="Call the exchange-rate endpoint">
    `GET /openapi/v1/mc-account/exchange-rate/query/CRYPTO/BTC/USDT` requires only `READ` and is ideal for verifying your signing implementation.

    ```bash
    ACCESS_KEY='YOUR_ACCESS_KEY'
    SECRET_KEY='YOUR_SECRET_KEY'
    URI='/openapi/v1/mc-account/exchange-rate/query/CRYPTO/BTC/USDT'
    TIMESTAMP=$(python3 -c 'import time; print(int(time.time()*1000))')
    NONCE=$(python3 -c 'import uuid; print(uuid.uuid4())')
    
    SIGNATURE=$(ACCESS_KEY="$ACCESS_KEY" SECRET_KEY="$SECRET_KEY" URI="$URI" TIMESTAMP="$TIMESTAMP" NONCE="$NONCE" python3 << 'PY'
    import base64, hashlib, hmac, os
    method = "GET"
    uri = os.environ["URI"]
    access_key = os.environ["ACCESS_KEY"]
    secret_key = os.environ["SECRET_KEY"]
    timestamp = os.environ["TIMESTAMP"]
    nonce = os.environ["NONCE"]
    headers = "&".join(
        f"{k}={v}"
        for k, v in sorted(
            {
                "x-access-key": access_key,
                "x-nonce": nonce,
                "x-timestamp": timestamp,
            }.items()
        )
    )
    string_to_sign = f"{method}\n{uri}\n{headers}\n{timestamp}\n{nonce}\n"
    sig = base64.b64encode(
        hmac.new(secret_key.encode(), string_to_sign.encode(), hashlib.sha256).digest()
    ).decode()
    print(sig)
    PY
    )
    
    curl -s \
      -H "X-Access-Key: ${ACCESS_KEY}" \
      -H "X-Signature: ${SIGNATURE}" \
      -H "X-Timestamp: ${TIMESTAMP}" \
      -H "X-Nonce: ${NONCE}" \
      "https://gateway.mcconnects.com${URI}"
    ```

    A successful response:

    ```json
    {
      "status": 200,
      "code": "200",
      "success": true,
      "data": 98500.12
    }
    ```
  </Step>
