## 查询未成交订单列表（挂单）V2

`GET /openapi/v1/mc-trade/trade/orders/pending/v2` — 权限 `READ`。

根据当前用户的 UID 查询未成交订单列表（挂单），UID 从请求头 `X-UID` 获取。

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| symbol | string | 否 | 交易品种，可选 |
| login | string | 是 | 交易账户登录号 |

### 响应 `data` 字段

`data` 为对象数组。元素字段见下表。

`data[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| order | string | 订单号，主键 |
| externalID | string | 外部ID，外部系统关联的ID |
| login | string | 交易账户登录号 |
| dealer | string | 交易商ID |
| symbol | string | 交易品种，如EURUSD、GBPUSD等 |
| digits | integer | 价格精度，交易品种的价格小数位数 |
| digitsCurrency | integer | 货币精度，交易品种的货币小数位数 |
| contractSize | string | 合约大小，每手合约的标准大小 |
| state | integer | 订单状态 |
| reason | integer | 原因，订单变更的原因代码 |
| timeSetup | string | 下单时间，订单创建的时间戳，毫秒级，长度13位 |
| timeExpiration | string | 到期时间，订单的到期时间戳，毫秒级，长度13位 |
| timeDone | string | 完成时间，订单完成的时间戳，毫秒级，长度13位 |
| timeSetupMsc | string | 下单时间（毫秒），订单创建的时间戳（毫秒），毫秒级，长度13位 |
| timeDoneMsc | string | 完成时间（毫秒），订单完成的时间戳（毫秒），毫秒级，长度13位 |
| modifyFlags | integer | 修改标志，订单修改的标志位 |
| type | integer | 订单类型，如买入、卖出等 |
| typeFill | integer | 成交类型，订单的填充方式 |
| typeTime | integer | 有效时间类型，订单的有效期类型 |
| priceOrder | string | 订单价格，订单的执行价格 |
| priceOrderDisplay | string | 订单价格展示值 |
| priceOrderScale | integer | 订单价格展示小数位 |
| priceTrigger | string | 触发价格，订单的触发价格 |
| priceTriggerDisplay | string | 触发价格展示值 |
| priceTriggerScale | integer | 触发价格展示小数位 |
| priceCurrent | string | 当前价格，订单的当前市场价格 |
| priceCurrentDisplay | string | 当前价格展示值 |
| priceCurrentScale | integer | 当前价格展示小数位 |
| priceSL | string | 止损价格，设置的止损价位 |
| priceSlDisplay | string | 止损价格展示值 |
| priceSlScale | integer | 止损价格展示小数位 |
| priceTP | string | 止盈价格，设置的止盈价位 |
| priceTpDisplay | string | 止盈价格展示值 |
| priceTpScale | integer | 止盈价格展示小数位 |
| volumeInitialExt | string | 初始交易量（扩展精度） |
| volumeCurrentExt | string | 当前交易量（扩展精度） |
| quantity | string | 用户数量，当前剩余扩展交易量经持仓量精度换算后的值 |

## 查询历史订单列表V3

`GET /openapi/v1/mc-trade/trade/orders/history/v3` — 权限 `READ`。

根据 uid 和账户数据类型(SPOT/CONTRACT/SPOT_CONTRACT)查询历史委托订单列表，包含现货和合约数据

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| size | integer | 否 | 每页显示条数 |
| current | integer | 否 | 当前页码 |
| orderBy | string | 否 |  |
| sortOrder | string | 否 |  |
| type | string | 是 | 账户数据类型：SPOT-现货，CONTRACT-合约，SPOT_CONTRACT-现货与合约合并; 可选值：`SPOT`, `CONTRACT`, `SPOT_CONTRACT` |
| from | integer | 是 | 开始时间戳（Unix时间戳，秒） |
| to | integer | 是 | 结束时间戳（Unix时间戳，秒） |
| symbol | string | 否 | 交易品种名 |
| cursorTimeSetupMsc | integer | 否 | CURSOR 模式游标时间，取上一页最后一条 records.timeSetupMsc，毫秒时间戳；与 cursorOrderId 成对传入时走游标分页 |
| cursorOrderId | integer | 否 | CURSOR 模式游标订单号，取上一页最后一条 records.order；与 cursorTimeSetupMsc 成对传入时走游标分页 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | array | 当前页记录列表 |
| total | integer | 总数。普通 Page 分页返回真实总数；关闭 count 或使用 cursor 翻页的接口可能返回 0，此时以 records 和 hasNext 为准 |
| size | integer | 每页条数 |
| current | integer | 当前页码 |
| pages | integer | 总页数。普通 Page 分页返回真实总页数；关闭 count 或使用 cursor 翻页的接口可能返回 0，平台成交列表使用上一页最后一条记录的 timeMsc/dealId 作为下一页 cursor |
| hasPrevious | boolean | 是否有上一页 |
| hasNext | boolean | 是否有下一页 |

## 查询订单历史 CSV 导出任务

`GET /openapi/v1/mc-trade/trade/orders/history/export-tasks/{taskId}` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| taskId | string | 是 | 最短长度: 1; 最长长度: 64 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务的不透明唯一标识 |
| dataset | string | 任务数据集; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | 创建时冻结的规范语言码 |
| sourceView | string | 原来源 SPOT、CONTRACT、PORTFOLIO；旧任务可能为空; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; 可为空 |
| retryOfTaskId | string | 当前列表重试关联的原任务；非重试为空; 可为空 |
| retryContext | object | 仅安全完整且授权有效的 FAILED 任务提供重试条件; 可为空 |
| status | string | 任务状态; 可选值：`QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | 失败原因；仅 FAILED 状态非空; 可选值：`GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; 可为空 |
| createdAt | integer | 创建时间，Unix 毫秒，UTC epoch |
| updatedAt | integer | 更新时间，Unix 毫秒，UTC epoch |
| expiresAt | integer | 绝对过期时间，Unix 毫秒，UTC epoch |
| rowCount | integer | 导出行数；未完成或超过上限时为空; 可为空 |
| fileName | string | 下载文件名；仅成功任务非空; 可为空 |
| downloadAvailable | boolean | 服务端确认对象完整且未过期时为 true |

`retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 原失败任务标识 |
| createRequest | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

`retryContext.createRequest` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `<key>` | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/trade/orders/history/export-tasks/TASK_DEMO_001" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## 创建订单历史 CSV 导出任务

`POST /openapi/v1/mc-trade/trade/orders/history/export-tasks` — 权限 `READ`.

### 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| clientRequestId | string | 是 | 客户端幂等请求标识，去除首尾空白后为 1 到 64 个可打印字符; 最短长度: 0; 最长长度: 64 |
| sourceView | string | 否 | 来源列表：SPOT、CONTRACT、PORTFOLIO、VAULT；旧调用可不传; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; 可为空 |
| type | string | 是 | 账户数据类型：SPOT、CONTRACT 或 SPOT_CONTRACT; 可选值：`SPOT`, `CONTRACT`, `SPOT_CONTRACT` |
| from | integer | 是 | 查询开始时间，Unix 秒，UTC epoch |
| to | integer | 是 | 查询结束时间，Unix 秒，UTC epoch；必须不早于 from |
| symbol | string | 否 | 可选交易品种；空值表示全部品种; 最短长度: 0; 最长长度: 64 |
| sort | string | 是 | 固定倒序规则；成交与订单使用各自的排序枚举; 可选值：`DEAL_TIME_DESC`, `ORDER_TIME_DESC` |
| language | string | 否 | CSV 语言标签；别名、空值与未知标签由共享目录规范化 |
| timeZone | string | 是 | IANA 时区标识 |
| direction | string | 否 | ALL 全部、BUY 买、SELL 卖；缺省为 ALL; 可选值：`ALL`, `BUY`, `SELL` |

### 响应 `data` 字段

HTTP `202 Accepted`; 任务异步生成。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务的不透明唯一标识 |
| dataset | string | 任务数据集; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | 创建时冻结的规范语言码 |
| sourceView | string | 原来源 SPOT、CONTRACT、PORTFOLIO；旧任务可能为空; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; 可为空 |
| retryOfTaskId | string | 当前列表重试关联的原任务；非重试为空; 可为空 |
| retryContext | object | 仅安全完整且授权有效的 FAILED 任务提供重试条件; 可为空 |
| status | string | 任务状态; 可选值：`QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | 失败原因；仅 FAILED 状态非空; 可选值：`GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; 可为空 |
| createdAt | integer | 创建时间，Unix 毫秒，UTC epoch |
| updatedAt | integer | 更新时间，Unix 毫秒，UTC epoch |
| expiresAt | integer | 绝对过期时间，Unix 毫秒，UTC epoch |
| rowCount | integer | 导出行数；未完成或超过上限时为空; 可为空 |
| fileName | string | 下载文件名；仅成功任务非空; 可为空 |
| downloadAvailable | boolean | 服务端确认对象完整且未过期时为 true |

`retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 原失败任务标识 |
| createRequest | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

`retryContext.createRequest` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `<key>` | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-trade/trade/orders/history/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \

  "from": 1761955200,
```
