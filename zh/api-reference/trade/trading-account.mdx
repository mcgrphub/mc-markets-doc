## 当前持仓查询V2

`GET /openapi/v1/mc-trade/account/positions/current/v2` — 权限 `READ`。

根据当前用户的 UID 查询当前所有未平仓持仓（UID 从请求头 `X-UID` 获取）。MT5 多处用整型表示浮点数以避免精度问题：不带 Ext 后缀的字段表示 4 位小数（转浮点数需除以 10000）；带 Ext 后缀的字段表示 8 位小数（转浮点数需除以 100000000）。例如 `mt5_positions` 表中持仓量有 `Volume` 与 `VolumeExt`。

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| login | string | 是 | 交易账户或现货账户登录号 |
| symbol | string | 否 | 交易品种，可选 |
| positionType | string | 否 | 不传或传ALL-全部，COLLATERAL-仅抵押品，SYMBOL-仅交易持仓 |

### 响应 `data` 字段

`data` 为对象数组。元素字段见下表。

`data[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| position | string | 持仓编号，持仓唯一标识 |
| externalID | string | 外部ID，外部系统关联的ID |
| login | string | 交易账户登录号 |
| dealer | string | 交易商ID |
| symbol | string | 交易品种，如EURUSD、GBPUSD等 |
| action | integer | 操作类型，0-买入，1-卖出 |
| digits | integer | 价格精度，交易品种的价格小数位数 |
| digitsCurrency | integer | 货币精度，交易品种的货币小数位数 |
| profitCurrencyDigits | integer | 盈亏货币展示精度，优先取持仓货币精度，其次品种盈亏货币精度，最后回退 2 |
| reason | integer | 原因，持仓变更的原因代码 |
| contractSize | string | 合约大小，每手合约的标准大小 |
| timeCreate | string | 创建时间，持仓创建的时间戳，毫秒级，长度13位 |
| timeUpdate | string | 更新时间，持仓最后更新的时间戳，毫秒级，长度13位 |
| timeCreateMsc | string | 创建时间（毫秒），持仓创建的时间戳（毫秒），长度13位 |
| timeUpdateMsc | string | 更新时间（毫秒），持仓最后更新的时间戳（毫秒），长度13位 |
| priceOpen | string | 开仓价格，持仓的开仓价格 |
| priceOpenDisplay | string | 开仓价格展示值 |
| priceOpenScale | integer | 开仓价格展示小数位 |
| priceCurrent | string | 当前价格，持仓的当前市场价格 |
| priceCurrentDisplay | string | 当前价格展示值 |
| priceCurrentScale | integer | 当前价格展示小数位 |
| priceSL | string | 止损价格，设置的止损价位 |
| priceSlDisplay | string | 止损价格展示值 |
| priceSlScale | integer | 止损价格展示小数位 |
| priceTP | string | 止盈价格，设置的止盈价位 |
| priceTpDisplay | string | 止盈价格展示值 |
| priceTpScale | integer | 止盈价格展示小数位 |
| volumeExt | string | 持仓量（扩展精度），需按持仓量精度换算 |
| volumeDisplay | string | 持仓手数展示值 |
| volumeScale | integer | 持仓手数展示小数位 |
| positionValueDisplay | string | 持仓价值展示值 |
| positionValueScale | integer | 持仓价值展示小数位 |
| profit | string | 盈亏，当前持仓的浮动盈亏金额 |
| profitDisplay | string | 盈亏展示值 |
| profitScale | integer | 盈亏展示小数位 |
| storage | string | 库存费，持仓的隔夜利息/库存费 |
| rateProfit | string | 盈亏汇率，计算盈亏时使用的汇率 |
| rateMargin | string | 保证金汇率，计算保证金时使用的汇率 |
| expertID | string | 专家顾问ID，如果持仓由 EA 创建，则记录 EA 的 ID |
| expertPositionID | string | 专家顾问持仓ID，EA创建的持仓关联ID |
| activationMode | integer | 激活模式，挂单的激活模式（如挂单激活方式） |
| activationTime | string | 激活时间，挂单的激活时间戳 |
| activationPrice | string | 激活价格，挂单的激活价格 |
| activationFlags | integer | 激活标志，挂单激活的标志位 |
| volume | string | 手数（标准精度），需按持仓量精度换算 |
| fundingRate | string | 资金费 |
| interest | string | 利息 |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-trade/account/positions/current/v2" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "login=10000001"
```

## 按交易品种 symbol 查询合约多空总持仓手数

`GET /openapi/v1/mc-trade/account/contract-volume-by-symbol` — 权限 `公开访问`。

symbol 对应 mt5_positions.Symbol；仅统计 Path 以 CFD 开头的品种；手数 = VolumeExt/1e8。

没有匹配持仓时，`longVolume` 和 `shortVolume` 均返回 `0`；这不表示资源不存在。

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| symbol | string | 是 | 交易品种 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| symbol | string | 交易品种 |
| longVolume | string | 多头持仓手数合计 |
| shortVolume | string | 空头持仓手数合计 |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-trade/account/contract-volume-by-symbol" \
  --data-urlencode "symbol=BTCUSDT"
```
