## 查询当前用户三类 CSV 导出历史

`GET /openapi/v1/mc-trade/export-tasks` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageSize | integer | 否 | 每页条数，范围 1 到 100；首次请求默认 20; 最小值: 1; 最大值: 100 |
| dataset | string | 否 | 隔离查询的数据集，必须和 sourceView 同时提供; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| sourceView | string | 否 | 隔离查询的来源：SPOT、CONTRACT、PORTFOLIO; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO` |
| cursor | string | 否 | 服务端签名的不可变快照游标; 最短长度: 1; 最长长度: 2048 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | array | 当前页任务摘要 |
| pageSize | integer | 本页请求条数 |
| snapshotAt | integer | 本次游标快照时间，Unix 毫秒，UTC epoch |
| hasMore | boolean | 是否还有下一页 |
| nextCursor | string | 下一页游标；无下一页时为空 |
| pollAfterMs | integer | 当前页有活动任务时建议轮询间隔，毫秒 |

`items[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务的不透明唯一标识 |
| dataset | string | 任务数据集；可选值：`DEAL_HISTORY`、`ORDER_HISTORY`、`FUNDING_FEE_HISTORY`、`POSITION_CURRENT`、`ORDER_CURRENT` |
| language | string | 创建时冻结的规范语言码 |
| sourceView | string | 原来源 SPOT、CONTRACT、PORTFOLIO；旧任务可能为空 |
| retryOfTaskId | string | 当前列表重试关联的原任务；非重试为空 |
| retryContext | object | 失败任务的安全重试条件；客户端必须生成新的 clientRequestId |
| status | string | 任务状态；可选值：`QUEUED`、`RUNNING`、`SUCCEEDED`、`EMPTY`、`OVER_LIMIT`、`FAILED` |
| failureReason | string | 失败原因；仅 FAILED 状态非空；可选值：`GENERATION`、`UPLOAD`、`RESTART`、`TIMEOUT` |
| createdAt | integer | 创建时间，Unix 毫秒，UTC epoch |
| updatedAt | integer | 更新时间，Unix 毫秒，UTC epoch |
| expiresAt | integer | 绝对过期时间，Unix 毫秒，UTC epoch |
| rowCount | integer | 导出行数；未完成或超过上限时为空 |
| fileName | string | 下载文件名；仅成功任务非空 |
| downloadAvailable | boolean | 服务端确认对象完整且未过期时为 true |

`items[].retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 原失败任务标识 |
| createRequest | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

`items[].retryContext.createRequest` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `<key>` | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \

  -H "X-Nonce: YOUR_NONCE"
```
