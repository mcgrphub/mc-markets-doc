## 接口列表

| 方法 | 路径 | 权限 | 描述 |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-trade/export-tasks | READ | 查询当前用户三类 CSV 导出历史 |

## 查询当前用户三类 CSV 导出历史

`GET /openapi/v1/mc-trade/export-tasks` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageSize | integer | 否 | 每页条数，最大 100 |
| dataset | string | 否 | 隔离查询的数据集，必须和 sourceView 同时提供; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| sourceView | string | 否 | 隔离查询的来源：SPOT、CONTRACT、PORTFOLIO; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| cursor | string | 否 | 服务端签名的不可变快照游标; 最长长度: 2048 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | array | 当前页任务摘要 |
| pageSize | integer | 本页请求条数 |
| snapshotAt | integer | 本次游标快照时间，Unix 毫秒，UTC epoch |
| hasMore | boolean | 是否还有下一页 |
| nextCursor | string | 下一页游标；无下一页时为空; 可为空 |
| pollAfterMs | string | 当前页有活动任务时建议轮询间隔，毫秒; 可为空 |

`items[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务的不透明唯一标识 |
| dataset | string | 任务数据集; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | 创建时冻结的规范语言码 |
| sourceView | string | 原来源 SPOT、CONTRACT、PORTFOLIO；旧任务可能为空; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; 可为空 |
| retryOfTaskId | string | 当前列表重试关联的原任务；非重试为空; 可为空 |
| retryContext | object | 仅安全完整且授权有效的 FAILED 任务提供重试条件; 可为空 |
| status | string | 任务状态; 可选值：`QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | 失败原因；仅 FAILED 状态非空; 可选值：`GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; 可为空 |
| createdAt | integer | 创建时间，Unix 毫秒，UTC epoch |
| updatedAt | integer | 更新时间，Unix 毫秒，UTC epoch |
| expiresAt | integer | 绝对过期时间，Unix 毫秒，UTC epoch |
| rowCount | integer | 导出行数；未完成或超过上限时为空; 可为空 |
| fileName | string | 下载文件名；仅成功任务非空; 可为空 |
| downloadAvailable | boolean | 服务端确认对象完整且未过期时为 true |

`items[].retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 原失败任务标识 |
| createRequest | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

`items[].retryContext.createRequest` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `<key>` | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## 创建当前列表 CSV 导出任务

`POST /openapi/v1/mc-trade/export-tasks` — 权限 `READ`.

当前列表创建仅支持 `POSITION_CURRENT`、`ORDER_CURRENT`，不接受历史数据集。仓位必须传字符串 `filters.login`，来源不得为 `SPOT`；`positionType` 可为 `SYMBOL` 或 `COLLATERAL`。当前委托可传旧 `login`，或传 `accounts` 账户集合；集合须与当前页面的可信账户全集一致。所有账户仍需通过归属校验。

### 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| clientRequestId | string | 是 | trim 后 1 至 64 个可打印字符的幂等标识 |
| dataset | string | 是 | POSITION_CURRENT 仓位、ORDER_CURRENT 当前委托; 可选值：`POSITION_CURRENT`, `ORDER_CURRENT` |
| sourceView | string | 是 | SPOT、CONTRACT、PORTFOLIO、VAULT；仓位不允许 SPOT; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| filters | object | 是 | 仓位：login、symbol、positionType、direction；当前委托：accounts 或旧 login、symbol、direction |
| sort | object | 否 | 可空的白名单排序 |
| language | string | 否 | 共享目录规范化语言标签，可空 |
| timeZone | string | 是 | 文件展示使用的 IANA 时区 |
| csvCatalogVersion | string | 否 | 当前数据集支持的冻结列版本，可空 |
| retryOfTaskId | string | 否 | 同 owner、同列表的 FAILED 原任务，可空 |

`sort` 字段（传入 sort 时，以下两项均必填）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| field | string | 该数据集允许的原始排序字段 |
| direction | string | `ASC` / `DESC` |

### 响应 `data` 字段

HTTP `202 Accepted`; 任务异步生成。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务的不透明唯一标识 |
| dataset | string | 任务数据集; 可选值：`DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | 创建时冻结的规范语言码 |
| sourceView | string | 原来源 SPOT、CONTRACT、PORTFOLIO；旧任务可能为空; 可选值：`SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; 可为空 |
| retryOfTaskId | string | 当前列表重试关联的原任务；非重试为空; 可为空 |
| retryContext | object | 仅安全完整且授权有效的 FAILED 任务提供重试条件; 可为空 |
| status | string | 任务状态; 可选值：`QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | 失败原因；仅 FAILED 状态非空; 可选值：`GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; 可为空 |
| createdAt | integer | 创建时间，Unix 毫秒，UTC epoch |
| updatedAt | integer | 更新时间，Unix 毫秒，UTC epoch |
| expiresAt | integer | 绝对过期时间，Unix 毫秒，UTC epoch |
| rowCount | integer | 导出行数；未完成或超过上限时为空; 可为空 |
| fileName | string | 下载文件名；仅成功任务非空; 可为空 |
| downloadAvailable | boolean | 服务端确认对象完整且未过期时为 true |

`retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 原失败任务标识 |
| createRequest | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

`retryContext.createRequest` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `<key>` | object | 原公开创建参数；不含 owner、内部账户集合或旧幂等键 |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "clientRequestId": "current-export-demo-001",
  "dataset": "POSITION_CURRENT",
  "sourceView": "CONTRACT",
  "filters": {
    "login": "10000001",
    "positionType": "SYMBOL"
  },
  "timeZone": "Asia/Shanghai"
}'
```

## 下载当前列表 CSV

`GET /openapi/v1/mc-trade/export-tasks/{taskId}/download` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| taskId | string | 是 | 最短长度: 1; 最长长度: 64 |

### 响应

HTTP `302 Found`; `Location` 为限时下载地址，`Cache-Control: no-store`。无 JSON `data`。

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks/TASK_DEMO_001/download" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
