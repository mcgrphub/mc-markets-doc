## 分页查询成交订单

`GET /openapi/v1/mc-account/deal-order` — 权限 `READ`。

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| size | integer | 否 | 分页每页条数 |
| current | integer | 否 | 分页当前页码，从 1 开始 |
| orderBy | string | 否 | 支持多字段排序，用逗号分隔 |
| orderDirection | string | 否 | ASC升序/DESC降序，多字段时用逗号分隔; 可选值：`ASC`, `DESC` |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | array | 当前页记录列表 |
| total | integer | 总记录数 |
| size | integer | 每页条数 |
| current | integer | 当前页码 |
| pages | integer | 总页数 |
| hasPrevious | boolean | 是否有上一页 |
| hasNext | boolean | 是否有下一页 |

`records[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| remark | string | 备注信息 |
| dealAmount | string | 成交价值(USDC) |
| dealAmountDisplay | string | 成交价值展示值 |
| dealAmountScale | integer | 成交价值展示小数位 |
| commission | string | 费用 |
| commissionDisplay | string | 费用展示值 |
| commissionScale | integer | 费用展示小数位 |
| profit | string | 已实现盈亏 |
| profitDisplay | string | 已实现盈亏展示值 |
| profitScale | integer | 已实现盈亏展示小数位 |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-account/deal-order" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "size=1" \
  --data-urlencode "current=1"
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| dealId | integer | 是 | 成交单 ID |

| positionId | string | 持仓单ID |
| orderId | string | 订单号 |
| dealId | string | 成交单号 |
| dealTime | string | 成交时间 |
| dealTimeTimestamp | string | 成交时间毫秒时间戳 |

| baseSymbolId | string | 基础币种ID |
| quoteSymbolId | string | 计价币种ID |
| entry | string | 方向; 可选值：`ENTRY_IN`, `ENTRY_OUT`, `ENTRY_INOUT`, `ENTRY_OUT_BY` |
| price | string | 委托价格 |
| pricePosition | string | 成交均价 |
| lot | string | 委托数量 |
| volumeClosed | string | 成交数量 |
| storage | string | 库存费 |
| commission | string | 手续费 |
| commissionDisplay | string | 手续费展示值，带符号向上取整后固定6位小数 |
