## 金库账户提现

`POST /openapi/v1/mc-account/mlp/account/withdraw` — 权限 `TRADE`。

金库账户提现，从金库账户转出到资金账户，然后划入交易账户。优先扣减本金，再扣减收益。

### 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| trackingId | string | 是 | 用于跟踪请求的唯一标识 |
| symbolId | string | 是 | 币种ID |
| amount | number | 是 | 提现金额 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | string | `data` 为该类型标量 |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-account/mlp/account/withdraw" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "trackingId": "vault-withdraw-demo-001",
  "symbolId": "1",
  "amount": 10
}'
```

## 本人金库存款记录

`GET /openapi/v1/mc-account/mlp/deposits` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| current | integer | 否 | 页码，默认1; 最小值: 1 |
| size | integer | 否 | 页大小，1到100，默认20; 最小值: 1; 最大值: 100 |
| symbolId | string | 否 | 当前配置币种ID，可空 |
| fromMs | integer | 否 | 包含的开始时间，UTC epoch毫秒，可空; 最小值: 0 |
| toMs | integer | 否 | 包含的结束时间，UTC epoch毫秒，可空; 最小值: 0 |
| orderDirection | string | 否 | ASC或DESC，默认DESC; 可选值：`ASC`, `DESC` |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | array | 当前页记录 |
| current | integer | 页码 |
| size | integer | 页大小 |
| total | integer | 过滤后的总条数 |
| asOfMs | integer | 本次读取时间，UTC epoch毫秒 |

`records[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| recordKey | string | 内部本金记录标识 |
| symbolId | string | 币种ID |

| unlockAtMs | integer | 解锁时间，UTC epoch毫秒 |
| lockedPrincipal | string | 锁定本金，原币 |
| withdrawablePrincipal | string | 未占用到期本金，原币 |
| remainingPrincipal | string | 未成功取出本金，原币 |
| withdrawnPrincipal | string | 成功取出本金，原币 |
| status | string | LOCKED或UNLOCKED |
| isLegacy | boolean | 存量本金投影 |
| depositId | string | 原交易编号，无法还原为null |
| depositedAmount | string | 原成功存入数量，未知为null |
| depositedAtMs | integer | 成功存入时间，UTC epoch毫秒，未知为null |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/mlp/deposits" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
