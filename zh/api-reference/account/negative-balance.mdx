## 查询本人负结余账户

`GET /openapi/v1/mc-account/negative-balance/accounts` — 权限 `READ`.


### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| accounts | array | 负结余账户；完整查询且全部非负时才为空 |
| snapshotAtMs | string | 权威快照时刻，Unix毫秒UTC |

`accounts[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| accountId | string | 本人合约账户ID |
| asset | string | 结算币种 |
| balance | string | 负数权威余额十进制字符串 |
| amountToCover | string | 需补足的正数金额，USDC6位/其它币种8位向上取整 |
| hourlyRate | string | 当前小时适用利率百分数字符串，最多6位小数 |
| eventId | string | 可选已核实周期标识，未核实时不返回 |
| negativeSinceMs | string | 可选已核实周期开始，Unix毫秒UTC；未核实时不返回 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/negative-balance/accounts" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
