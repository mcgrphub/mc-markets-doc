## 接口列表

| 方法 | 路径 | 权限 | 描述 |
| --- | --- | --- | --- |
| GET | `/openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}` | READ | 查询资金费历史导出任务 |
| GET | `/openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}/download` | READ | 下载资金费历史 CSV |
| POST | /openapi/v1/mc-account/funding-fee-record/export-tasks | READ | 创建资金费历史导出任务 |

<Note>
需认证的接口请按 [认证](/zh/authentication) 使用 AK/SK 签名。公开访问接口无需签名。网关地址见 [基础 URL](/zh/api-reference/base-url)。
</Note>

该创建接口仅导出资金费历史，数据集固定为 `FUNDING_FEE_HISTORY`。任务状态使用共享响应视图，其余 `dataset` 枚举不表示此接口支持创建其它数据集。资金费任务的 `retryOfTaskId` 为 `null`；`retryContext` 仅在允许重试时返回原冻结条件，否则为 `null`。

## 查询资金费历史导出任务

`GET /openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| taskId | string | 是 | 任务唯一标识 |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务唯一标识 |
| dataset | string | 任务数据集；可选值：`FUNDING_FEE_HISTORY`、`SWAP_HISTORY`、`BALANCE`、`FUND_FLOW`、`DEPOSIT_WITHDRAW`。资金费创建接口固定使用 `FUNDING_FEE_HISTORY` |
| language | string | CSV 语言标签，由服务端规范化 |
| status | string | 异步任务状态；可选值：`QUEUED`、`RUNNING`、`SUCCEEDED`、`EMPTY`、`OVER_LIMIT`、`FAILED` |
| failureReason | string | 失败原因；仅失败任务适用；可选值：`RESTART`、`GENERATION`、`UPLOAD`、`TIMEOUT` |
| createdAt | string | 创建时间，UTC Unix 毫秒；JSON 字符串 |
| updatedAt | string | 更新时间，UTC Unix 毫秒；JSON 字符串 |
| expiresAt | string | 过期时间，UTC Unix 毫秒；JSON 字符串 |
| rowCount | integer | 数据行数，不含表头；尚未生成或超过上限时为 null |
| fileName | string | 可下载文件名，可为 null |
| downloadAvailable | boolean | 成功且未到期，并已校验文件元数据时为 true |
| sourceView | string | 来源视图；可选值：`SWAP`、`SPOT`、`CONTRACT`、`PORTFOLIO`、`VAULT`。旧调用未记录来源时为 null |
| retryOfTaskId | string | 关联的原失败任务 ID；资金费任务及普通创建任务为 null |
| retryContext | object | 可重试任务的原冻结条件；不满足重试条件时为 null |

`retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 当前失败任务的 ID |
| createRequest | object | 原创建端点接受的白名单字段，不含 clientRequestId；字段名与值取决于原请求 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/export-tasks/TASK_DEMO_001" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## 下载资金费历史 CSV

`GET /openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}/download` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| taskId | string | 是 | 任务唯一标识 |

### 响应

HTTP `302 Found`；`Location` 为限时下载地址，`Cache-Control: no-store`。响应不含 JSON `data`。

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/export-tasks/TASK_DEMO_001/download" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## 创建资金费历史导出任务

`POST /openapi/v1/mc-account/funding-fee-record/export-tasks` — 权限 `READ`.

### 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| clientRequestId | string | 是 | 非空客户端幂等标识，最多 64 个字符; 最短长度: 1; 最长长度: 64 |
| from | integer | 是 | 查询起始时间，UTC Unix 秒，非负 |
| to | integer | 是 | 查询结束时间，UTC Unix 秒，不早于 from |
| sort | string | 是 | 资金费记录固定倒序; 可选值：`DEAL_TIME_DESC` |
| sourceView | string | 否 | 来源视图；可选值：`SWAP`、`SPOT`、`CONTRACT`、`PORTFOLIO`、`VAULT`。不传或为 null 时保留旧调用的未知来源语义 |
| language | string | 否 | CSV 语言标签，由服务端规范化 |
| timeZone | string | 是 | IANA 时区标识 |

### 响应 `data` 字段

HTTP `202 Accepted`；任务异步生成，随后查询任务状态。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| taskId | string | 任务唯一标识 |
| dataset | string | 任务数据集；可选值：`FUNDING_FEE_HISTORY`、`SWAP_HISTORY`、`BALANCE`、`FUND_FLOW`、`DEPOSIT_WITHDRAW`。资金费创建接口固定使用 `FUNDING_FEE_HISTORY` |
| language | string | CSV 语言标签，由服务端规范化 |
| status | string | 异步任务状态；可选值：`QUEUED`、`RUNNING`、`SUCCEEDED`、`EMPTY`、`OVER_LIMIT`、`FAILED` |
| failureReason | string | 失败原因；仅失败任务适用；可选值：`RESTART`、`GENERATION`、`UPLOAD`、`TIMEOUT` |
| createdAt | string | 创建时间，UTC Unix 毫秒；JSON 字符串 |
| updatedAt | string | 更新时间，UTC Unix 毫秒；JSON 字符串 |
| expiresAt | string | 过期时间，UTC Unix 毫秒；JSON 字符串 |
| rowCount | integer | 数据行数，不含表头；尚未生成或超过上限时为 null |
| fileName | string | 可下载文件名，可为 null |
| downloadAvailable | boolean | 成功且未到期，并已校验文件元数据时为 true |
| sourceView | string | 来源视图；可选值：`SWAP`、`SPOT`、`CONTRACT`、`PORTFOLIO`、`VAULT`。旧调用未记录来源时为 null |
| retryOfTaskId | string | 关联的原失败任务 ID；资金费任务及普通创建任务为 null |
| retryContext | object | 可重试任务的原冻结条件；不满足重试条件时为 null |

`retryContext` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| originalTaskId | string | 当前失败任务的 ID |
| createRequest | object | 原创建端点接受的白名单字段，不含 clientRequestId；字段名与值取决于原请求 |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "clientRequestId": "export-demo-20261102-001",
  "from": 1761955200,
  "to": 1762041600,
  "sort": "DEAL_TIME_DESC",
  "timeZone": "Asia/Shanghai"
}'
```
