## 接口列表

| 方法 | 路径 | 权限 | 描述 |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-account/jurisdiction/access-result | 公开访问 | 查询访问地区结果 |

<Note>
需认证的接口请按 [认证](/zh/authentication) 使用 AK/SK 签名。公开访问接口无需签名。网关地址见 [基础 URL](/zh/api-reference/base-url)。
</Note>

## 查询访问地区结果

`GET /openapi/v1/mc-account/jurisdiction/access-result` — 权限 `公开访问`.

匿名或登录均可；结果不能授权业务写操作


### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| result | string | 访问结果; 可选值：`ACCESS_ALLOWED`, `JURISDICTION_RESTRICTED`, `JURISDICTION_UNKNOWN` |
| messageKey | string | 前端文案键；允许时为空字符串 |
| policyVersion | string | 不透明策略版本 |
| evaluatedAtMillis | integer | 评估完成时间，Unix 毫秒 UTC epoch |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/jurisdiction/access-result"
```

## 查询完整司法管辖区门禁

`GET /openapi/v1/mc-account/jurisdiction/evaluation` — 权限 `READ`.

只读预检；最终写请求会重新评估

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| action | string | 否 |  |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| decision | string | 门禁决定; 可选值：`PASS`, `KYC_REQUIRED`, `JURISDICTION_RESTRICTED`, `JURISDICTION_UNKNOWN` |
| reasonSource | string | 决定来源；不返回具体国家; 可选值：`NONE`, `ACCESS_COUNTRY`, `IDENTITY_COUNTRY`, `BASIC_KYC` |
| policyVersion | string | 不透明策略版本 |
| evaluatedAtMillis | integer | 评估完成时间，Unix 毫秒 UTC epoch |
| retryable | boolean | 客户端是否可在事实更新后重试 |
| messageKey | string | 前端文案键；通过时为空字符串 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/jurisdiction/evaluation" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
