## 用户金库市场列表

`GET /openapi/v1/mc-account/user-vaults` — 权限 `READ`.

### 查询 / 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 |  |
| sort | string | 否 |  |
| current | integer | 否 |  |
| size | integer | 否 |  |
| include | string | 否 | 可选扩展：sparkline=返回近30日净值 sparkline |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | array | 当前页记录列表 |
| total | integer | 总记录数 |
| size | integer | 每页条数 |
| current | integer | 当前页码 |
| pages | integer | 总页数 |
| hasPrevious | boolean | 是否有上一页 |
| hasNext | boolean | 是否有下一页 |

`records[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| vaultId | string | 对外金库ID |
| name | string | 金库名称 |
| strategySummary | string | 策略摘要；列表与详情均返回 |
| status | string | 状态机枚举名；与 frozen 正交 |
| frozen | boolean | 运营冻结；与 status 正交 |
| navPerShare | number | 最近已发布每份净值；未发布为 null |
| aum | number | 费后总净值 AUM |
| totalShares | number | 已发行总份额；8位；不含待确认申购 |
| maxAumCap | number | AUM上限=seed×20，创建时固定 |
| capacityRatio | number | 容量占比=aum÷maxAumCap；上限无效时为 null |
| myShares | number | 当前登录用户在该池的已确认份额；无持仓为 0；未传 uid 时不填 |
| sparkline | array | 近30日净值 sparkline；仅 include=sparkline 时返回；无已发布点时为 null 或空列表 |
| ownerShareRatio | number | 管理人自持占比=管理人确认份额÷总确认份额；无份额时为 null |
| investedUserCount | integer | 当前持有确认份额的存款人数量（含管理人） |
| accruedPerformanceFee | number | 本池累计已结晶业绩费合计（USDC）；collectedPerformanceFee |
| collectedPerformanceFee | number | 累计已收结晶业绩费（USDC）；与 accruedPerformanceFee 同值，优先使用本字段 |
| performanceFeeRate | number | 业绩费率 [0,0.30] |
| minSubscription | number | 最小申购（USDC） |
| maxSubscription | number | 最大申购（USDC） |
| lastNavAt | integer | 最近净值发布时间，UTC epoch 毫秒 |
| createdAt | integer | 创建时间，UTC epoch 毫秒 |
| return30d | number | 近30日收益；不足两个已发布点时为 null |
| ownerUid | string | 创建者UID；市场列表不返回 |
| mt5Login | integer | 金库合约MT5 login；市场列表不返回 |

`records[].sparkline[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| asOf | integer | 估值时点，UTC epoch 毫秒 |
| navPerShare | number | 每份净值 |
| aum | number | 费后总净值 |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/user-vaults" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

### 查询 / 路径参数

| --- | --- | --- | --- |
| type | string | 否 |  |
| vaultId | string | 否 |  |
| current | integer | 否 |  |
| size | integer | 否 |  |

### 响应 `data` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | array | 当前页记录列表 |
| total | integer | 总记录数 |
| size | integer | 每页条数 |
| current | integer | 当前页码 |
| pages | integer | 总页数 |
| hasPrevious | boolean | 是否有上一页 |
| hasNext | boolean | 是否有下一页 |

`records[]` 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| recordId | string | 行ID：申赎=orderId；结算=settlementId；流水=eventId |
| vaultId | string | 金库ID |
| vaultName | string | 金库名称 |
| uid | string | 业务用户UID；C 端可空 |
| type | string | SUBSCRIPTION / REDEMPTION / FORCE_REDEMPTION / PERFORMANCE_FEE |
| applicationQuantity | number | 申请数量：申购=金额；赎回=份额；业绩费=应计金额 |
| applicationQuantityUnit | string | USDC 或 SHARE |

| grossPayout | number | 结晶：毛额 gross |
| costDelta | number | 结晶：成本扣减 |

| feeRate | number | 结晶：费率 |
| feeAmount | number | 结晶：业绩费金额 |

| occurredAt | integer | 业务发生时间 epoch 毫秒 |

  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
