MC OpenAPI 的列表接口主要使用 `current` 与 `size` 分页，响应列表位于 `data.records`。具体参数位置和可选过滤条件以各接口页为准。

<Note>
  行情排行榜接口使用另一种结构：请求参数为 `page` / `pageSize`，响应列表位于 `data.items`。不要在两种分页结构之间复用字段名。
</Note>

## 请求参数

常规分页接口在 GET query 或 POST JSON body 中接收：

<ParamField query="current" default="1" type="integer">
  当前页码，从 1 开始。
</ParamField>

<ParamField query="size" type="integer">
  每页条数。限制和默认值以具体接口 schema 为准。
</ParamField>

## 响应形式

常规分页对象位于业务响应的 `data` 中：

```json
{
  "status": 200,
  "message": "ok",
  "code": "200",
  "codeKey": null,
  "params": {},
  "localizedMessage": null,
  "success": true,
  "data": {
    "records": [
      {
        "transactionId": "T-1001",
        "amount": 125.5,
        "acSymbol": "USDT",
        "createTimeTimestamp": 1731657600000
      }
    ],
    "total": 132,
    "size": 20,
    "current": 1,
    "pages": 7,
    "hasPrevious": false,
    "hasNext": true
  }
}
```

翻页时优先读取 `hasNext`；如果响应没有该字段，再使用 `current < pages` 判断。

## Python：遍历交易记录

以下示例调用 `POST /openapi/v1/mc-account/transaction/transaction/record/page`。每一页都生成新的时间戳和 nonce，并对实际发送的 body 字节签名。

```python
import base64
import hashlib
import hmac
import json
import os
import time
import uuid

import requests

BASE_URL = "https://gateway.mcconnects.com"
ACCESS_KEY = os.environ["MC_ACCESS_KEY"]
SECRET_KEY = os.environ["MC_SECRET_KEY"]


def signed_headers(method: str, path: str, body: bytes) -> dict[str, str]:
    timestamp = str(int(time.time() * 1000))
    nonce = str(uuid.uuid4())
    canonical_headers = (
        f"x-access-key={ACCESS_KEY}&x-nonce={nonce}&x-timestamp={timestamp}"
    )
    body_hash = hashlib.sha256(body).hexdigest()
    string_to_sign = "\n".join(
        [method, path, canonical_headers, timestamp, nonce, body_hash]
    ) + "\n"
    signature = base64.b64encode(
        hmac.new(
            SECRET_KEY.encode(), string_to_sign.encode(), hashlib.sha256
        ).digest()
    ).decode()
    return {
        "X-Access-Key": ACCESS_KEY,
        "X-Signature": signature,
        "X-Timestamp": timestamp,
        "X-Nonce": nonce,
        "Content-Type": "application/json",
    }


def fetch_all_transactions(page_size: int = 20) -> list[dict]:
    path = "/openapi/v1/mc-account/transaction/transaction/record/page"
    current = 1
    items = []

    while True:
        body = json.dumps(
            {"current": current, "size": page_size},
            separators=(",", ":"),
        ).encode()
        response = requests.post(
            BASE_URL + path,
            headers=signed_headers("POST", path, body),
            data=body,
            timeout=15,
        )
        response.raise_for_status()
        page = response.json()["data"]
        items.extend(page["records"])
        if not page.get("hasNext", current < page["pages"]):
            return items
        current += 1
```

完整签名规则、GET Query 排序和固定测试向量见 [认证](/zh/authentication)。

<Tip>
  使用满足业务需求的合理页大小，并对 `429` 与瞬时 `5xx` 执行带抖动的指数退避。
</Tip>
