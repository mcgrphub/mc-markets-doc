## 可轮询接口

下表中的频率是客户端建议值，不是后端 SLA 或固定限额。应结合业务时效、返回数据量和实际 `429` 调整。

| 你想检测 | 接口 | 建议起始频率 |
| --- | --- | --- |
| 新交易记录 | `POST /openapi/v1/mc-account/transaction/transaction/record/page` | 30–60 秒 |
| 理财账户变化 | `GET /openapi/v1/mc-account/finance/account/overview` | 60 秒 |
| 现货持仓变化 | `GET /openapi/v1/mc-account/fund/account/spot-account/positions?spotId=...` | 60–300 秒 |
| 资金费记录 | `GET /openapi/v1/mc-account/funding-fee-record/page/v2` | 300 秒 |
| USD 汇率更新 | `GET /openapi/v1/mc-account/exchange-rate/query/usd` | 60–300 秒 |

## 水位线与去重

1. 保存已处理记录的最大 `createTimeTimestamp`，并把 `transactionId` 作为幂等键。
2. 下一轮把 `createTimeStartTimestamp` 设为保存的水位线。
3. 使用 `current` / `size` 遍历 `data.records`，直到 `hasNext` 为 `false`。
4. 先持久化业务处理结果，再推进水位线。
5. 时间边界可能包含重复记录，接收端必须按业务 ID 去重。

## Python 示例

```python
import base64
import hashlib
import hmac
import json
import os
import time
import uuid

import requests

BASE_URL = "https://gateway.mcconnects.com"
ACCESS_KEY = os.environ["MC_ACCESS_KEY"]
SECRET_KEY = os.environ["MC_SECRET_KEY"]


def signed_headers(path: str, body: bytes) -> dict[str, str]:
    timestamp = str(int(time.time() * 1000))
    nonce = str(uuid.uuid4())
    canonical_headers = (
        f"x-access-key={ACCESS_KEY}&x-nonce={nonce}&x-timestamp={timestamp}"
    )
    body_hash = hashlib.sha256(body).hexdigest()
    string_to_sign = "\n".join(
        ["POST", path, canonical_headers, timestamp, nonce, body_hash]
    ) + "\n"
    signature = base64.b64encode(
        hmac.new(
            SECRET_KEY.encode(), string_to_sign.encode(), hashlib.sha256
        ).digest()
    ).decode()
    return {
        "X-Access-Key": ACCESS_KEY,
        "X-Signature": signature,
        "X-Timestamp": timestamp,
        "X-Nonce": nonce,
        "Content-Type": "application/json",
    }


def poll_transactions(watermark_ms: int, page_size: int = 20) -> tuple[list[dict], int]:
    path = "/openapi/v1/mc-account/transaction/transaction/record/page"
    current = 1
    records = []
    next_watermark = watermark_ms

    while True:
        body = json.dumps(
            {
                "current": current,
                "size": page_size,
                "createTimeStartTimestamp": watermark_ms,
            },
            separators=(",", ":"),
        ).encode()
        response = requests.post(
            BASE_URL + path,
            headers=signed_headers(path, body),
            data=body,
            timeout=15,
        )
        response.raise_for_status()
        page = response.json()["data"]

        for record in page["records"]:
            records.append(record)
            next_watermark = max(
                next_watermark,
                record.get("createTimeTimestamp", watermark_ms),
            )

        if not page.get("hasNext", current < page["pages"]):
            return records, next_watermark
        current += 1
```

完整签名规则见 [认证](/zh/authentication)，分页结构见 [分页](/zh/concepts/pagination)。

## 运行建议

- 为轮询间隔增加随机抖动，避免多个实例同时请求。
- 对 HTTP `429` 和瞬时 `5xx` 使用带抖动的指数退避。
- 不要把 Secret Key、水位线或响应中的账户数据写入公开日志。
- 查询现货持仓时使用真实 `spotId`，不要把 UID 当成该参数。
