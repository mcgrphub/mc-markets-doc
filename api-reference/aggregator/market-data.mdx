**Market data** endpoints return symbol rankings and candlestick data. The main default contract requires AK/SK signatures with `READ` permission. Anonymous access depends on gateway configuration. Paths use the `/openapi/v1/mc-aggregator/` prefix.

## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-aggregator/market-data/symbol-ranking | READ | Paginated symbol ranking by category and sort fields. |
| GET | /openapi/v1/mc-aggregator/market-data/kline | READ | Candlestick data by symbol, period, and time range. |

<Note>
  The interactive Playground is disabled. Examples use AK/SK signatures. Anonymous gateway access is environment-dependent; production configuration has not been verified. See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

## Symbol ranking

`GET /openapi/v1/mc-aggregator/market-data/symbol-ranking` — permission `READ`.

Paginated symbol ranking by category and sort dimensions.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| category | string | Yes | Category: CONTRACT, SPOT, CRYPTO, or TRADFI |
| subGroup | string | No | Traditional-finance subgroup: ALL, FOREX, METALS, INDICES, ENERGY, or STOCKS |
| hotOnly | boolean | No | Whether to return hot symbols only |
| sortBy | string | No | Sort field: symbol, bid, or change24hPct |
| sortOrder | string | No | Sort direction: asc or desc |
| page | integer | No | Page number, starting at 1; Minimum: 1 |
| pageSize | integer | No | Page size; maximum 100 |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| total | integer | Total number of symbols in current category |
| page | integer | Current page number |
| pageSize | integer | Page size |
| snapshotVersion | integer | Ranking snapshot version number |
| items | array | Ranking entries on current page |

`items[]` items:

| Field | Type | Description |
| --- | --- | --- |
| rank | integer | Global rank |
| symbol | string | Symbol Code |
| bid | string | Bid Price |
| change24hAbs | string | 24h change amount |
| change24hPct | string | 24h change percentage (decimal form, e.g., -0.0146 means -1.46%) |
| isHot | boolean | Whether hot |
| pricingDegree | integer | Price Decimal Places |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-aggregator/market-data/symbol-ranking" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "category=SPOT"
```

## Candlestick (K-line) data

`GET /openapi/v1/mc-aggregator/market-data/kline` — permission `READ`.

Query candlestick data by symbol, interval, and time range.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| symbol | string | Yes | Trading symbol code |
| period | integer | Yes | Intervals in minutes: 1 minute=1, 5 minutes=5, 15 minutes=15, 1 hour=60, 4 hours=240, 1 day=1440, 1 week=1440*7, 1 month=1440*30 |
| startTime | integer | No | Start time in Unix seconds |
| endTime | integer | Yes | End time in Unix seconds |
| limit | integer | No | Max rows per response; maximum 500 |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| pricingDegree | integer | Price precision, used to convert values to floating point numbers |
| klineDataList | array | K-line data list, in order: open price, close price, high price, low price, volume, second-level timestamp |
| klineDisplayList | array | K-line display field list, consistent with klineDataList order |

`klineDisplayList[]` items:

| Field | Type | Description |
| --- | --- | --- |
| openStr | string | Open price raw plain string |
| openDisplay | string | Open price display text |
| openScale | integer | Open price display decimal places |
| closeStr | string | Close price raw plain string |
| closeDisplay | string | Close price display text |
| closeScale | integer | Close price display decimal places |
| highStr | string | High price raw plain string |
| highDisplay | string | High price display text |
| highScale | integer | High price display decimal places |
| lowStr | string | Low price raw plain string |
| lowDisplay | string | Low price display text |
| lowScale | integer | Low price display decimal places |
| volumeStr | string | Trading volume raw plain string |
| volumeDisplay | string | Trading volume display text |
| volumeScale | integer | Trading volume display decimal places |
| timestamp | integer | Second-level timestamp |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-aggregator/market-data/kline" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "symbol=BTCUSDT" \
  --data-urlencode "period=60" \
  --data-urlencode "endTime=1762041600"
```
