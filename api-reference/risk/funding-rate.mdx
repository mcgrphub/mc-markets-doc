## Paginated funding rate history by trading symbol

`GET /openapi/v1/mc-risk/funding-rate` — permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| size | integer | No | Page size |
| current | integer | No | Current page number |
| orderBy | string | No | Multi-field sort; comma-separated fields |
| orderDirection | string | No | ASC ascending / DESC descending; comma-separated for multiple fields; Allowed values: `ASC`, `DESC` |
| symbol | string | Yes | Trading symbol |
| isSettlementRate | boolean | No | Whether this is the settlement rate; Allowed values: `true`, `false` |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| records | array | Records on the current page |
| total | integer | Total record count in standard mode; `0` in cursor mode |
| size | integer | Page size |
| current | integer | Current page number |
| pages | integer | Total page count in standard mode; `0` in cursor mode |
| hasPrevious | boolean | Whether a previous page exists |
| hasNext | boolean | Whether a next page exists |

`records[]` items:

| Field | Type | Description |
| --- | --- | --- |
| businessLineId | string | Business line ID |
| symbol | string | Trading symbol |
| fundingRate | string | Funding Rate |
| fundingRateStr | string | Funding rate raw decimal string |
| fundingRateDisplay | string | Funding rate display value |
| fundingRateScale | integer | Funding rate display decimal places |
| annualRateDisplay | string | Annualized funding rate display value |
| settlementPrice | string | Settlement Price |
| settlementPriceStr | string | Close price raw decimal string |
| settlementPriceDisplay | string | Close price display value |
| settlementPriceScale | integer | Close price display decimal places |
| longInterestRate | string | Long Interest Rate |
| longInterestRateStr | string | Long interest rate raw decimal string |
| shortInterestRate | string | Short Interest Rate |
| shortInterestRateStr | string | Short interest rate raw decimal string |
| isSettlementRate | boolean | Whether it is the settlement rate |
| nextSettlementTime | string | Next settlement time Unix timestamp |
| timestamp | string | Funding rate generation time Unix timestamp |
| settlementCycle | string | Settlement cycle (unit: seconds) |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-risk/funding-rate" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "size=1" \
  --data-urlencode "current=1" \
  --data-urlencode "symbol=BTCUSDT"
```
