Paths in this group use the `/openapi/v1/mc-trade/` prefix.

## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| PUT | /openapi/v1/mc-trade/trade/positions/modify | TRADE | Modify position |
| PUT | /openapi/v1/mc-trade/trade/orders/modify | TRADE | Order action: modify order |
| POST | /openapi/v1/mc-trade/trade/orders/create | TRADE | Order action: place order |
| POST | /openapi/v1/mc-trade/trade/orders/close | TRADE | Order action: close position |
| GET | /openapi/v1/mc-trade/trade/symbol/staticConfig | Public | Trading symbol info |
| GET | /openapi/v1/mc-trade/trade/slippage/estimate | READ | Get estimated slippage |
| GET | /openapi/v1/mc-trade/trade/mt5-group/staticInfo | READ | MT5 group static info |
| GET | /openapi/v1/mc-trade/trade/account/assets | READ | Get user assets |
| DELETE | /openapi/v1/mc-trade/trade/orders/cancel | TRADE | Order action: cancel order |

<Note>
  The interactive Playground is disabled. Sign requests with AK/SK as described in [Authentication](/authentication). See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

## Modify position

`PUT /openapi/v1/mc-trade/trade/positions/modify` — permission `TRADE`.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| login | string | Yes | Trading or spot account login |
| order | integer | Yes | Order ID |
| symbol | string | Yes | Trading pair, e.g. BTCUSDT; valid only when placing orders |
| type | integer | Yes | Order type: 0 OP_BUY market buy; 1 OP_SELL market sell; 2 OP_BUY_LIMIT buy limit; 3 OP_SELL_LIMIT sell limit; 4 OP_BUY_STOP buy stop; 5 OP_SELL_STOP sell stop; 6 OP_BUY_STOP_LIMIT buy stop-limit; 7 OP_SELL_STOP_LIMIT sell stop-limit; 8 OP_CLOSE_BY close by an opposite position in hedging mode |
| priceSL | number | No | New stop-loss price |
| priceTP | number | No | New take-profit price |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| code | string | MT5 Return Status Code |
| orderId | string | MT5 Order ID (if any) |
| params | object | MT5 return parameters (passed through to frontend or for business logic processing) |

`params` fields:

| Field | Type | Description |
| --- | --- | --- |
| `<key>` | object | MT5 return parameters (passed through to frontend or for business logic processing) |

```bash
curl -sS -X PUT "https://gateway.mcconnects.com/openapi/v1/mc-trade/trade/positions/modify" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "login": "10000001",
  "order": 123456789,
  "symbol": "BTCUSDT",
  "type": 0,
  "priceSL": 60000,
  "priceTP": 70000
}' 
```

## Order action: place order

`POST /openapi/v1/mc-trade/trade/orders/create` — permission `TRADE`.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| login | string | Yes | Trading or spot account login |
| symbol | string | Yes | Trading pair, e.g. BTCUSDT |
| volumeExt | integer | Yes | Volume scaled to position-volume precision; send 100000000 for 1 lot |
| price | number | No | Order price; defaults to 0 if omitted; 0 = market, any other value = limit |
| type | integer | Yes | Order type: 0 OP_BUY market buy; 1 OP_SELL market sell; 2 OP_BUY_LIMIT buy limit; 3 OP_SELL_LIMIT sell limit; 4 OP_BUY_STOP buy stop; 5 OP_SELL_STOP sell stop; 6 OP_BUY_STOP_LIMIT buy stop-limit; 7 OP_SELL_STOP_LIMIT sell stop-limit; 8 OP_CLOSE_BY close by an opposite position in hedging mode |
| position | integer | No | Position ID; defaults to 0 |
| typeFill | integer | Yes | Fill policy: 0 Fill or Kill requires a full fill or cancels the order; 1 Immediate or Cancel permits a partial fill and cancels the remainder; 2 Return puts the remainder back in the queue for supported exchange execution orders; 3 Book or Cancel places the order in the book only and cancels it if it would execute immediately |
| typeTime | integer | No | Time policy, default 0: 0 good till canceled; 1 valid for the day; 2 valid until a specified time; 3 valid until 00:00 on a specified date or the nearest trading time |
| expiration | integer | No | Expiration timestamp, required when typeTime=2. Default 0 means no automatic expiration |
| priceTrigger | number | No | Stop-limit order trigger price; defaults to 0 if omitted |
| priceSL | number | No | Stop-loss |
| priceTP | number | No | Take-profit price |
| userSlippageLimit | number | No | Maximum slippage limit for market orders entered by the user (market orders only); Minimum: 0 |
| frontMarketPrice | number | No | Optional reference market price; must not be negative; Minimum: 0 |
