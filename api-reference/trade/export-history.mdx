## List your CSV export history

`GET /openapi/v1/mc-trade/export-tasks` — permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| pageSize | integer | No | Page size; maximum 100 |
| dataset | string | No | Dataset filter; must be supplied together with sourceView; Allowed values: `DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| sourceView | string | No | Source filter: SPOT, CONTRACT, or PORTFOLIO; Allowed values: `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| cursor | string | No | Server-signed cursor for an immutable snapshot; Max length: 2048 |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| items | array | Task summaries on the current page |
| pageSize | integer | Requested page size |
| snapshotAt | integer | Cursor snapshot time in Unix milliseconds (UTC) |
| hasMore | boolean | Whether another page exists |
| nextCursor | string | Cursor for the next page; empty when no next page exists; Nullable |
| pollAfterMs | string | Suggested polling interval in milliseconds when the page includes active tasks; Nullable |

`items[]` items:

| Field | Type | Description |
| --- | --- | --- |
| taskId | string | Opaque unique task identifier |
| dataset | string | Task dataset; Allowed values: `DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | Normalized language code fixed at creation |
| sourceView | string | Original source: SPOT, CONTRACT, or PORTFOLIO; may be empty for older tasks; Allowed values: `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; Nullable |
| retryOfTaskId | string | Original task associated with this retry; empty for non-retry tasks; Nullable |
| retryContext | object | Retry conditions are provided only for complete, authorized FAILED tasks that are safe to retry; Nullable |
| status | string | Task status; Allowed values: `QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | Failure reason; populated only when status is FAILED; Allowed values: `GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; Nullable |
| createdAt | integer | Creation time in Unix milliseconds (UTC) |
| updatedAt | integer | Update time in Unix milliseconds (UTC) |
| expiresAt | integer | Absolute expiration time in Unix milliseconds (UTC) |
| rowCount | integer | Exported row count; empty before completion or when the limit is exceeded; Nullable |
| fileName | string | Download file name; populated only for successful tasks; Nullable |
| downloadAvailable | boolean | True when the service confirms the file is complete and unexpired |

`items[].retryContext` fields:

| Field | Type | Description |
| --- | --- | --- |
| originalTaskId | string | Original failed task identifier |
| createRequest | object | Original public creation parameters; excludes ownership context, internal account sets, and the previous idempotency key |

`items[].retryContext.createRequest` fields:

| Field | Type | Description |
| --- | --- | --- |
| `<key>` | object | Original public creation parameters; excludes ownership context, internal account sets, and the previous idempotency key |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## Create a current-list CSV export task

`POST /openapi/v1/mc-trade/export-tasks` — Permission `READ`.

Current-list creation supports only `POSITION_CURRENT` and `ORDER_CURRENT`, not historical datasets. Positions require a string `filters.login` and a source other than `SPOT`; `positionType` is `SYMBOL` or `COLLATERAL`. Pending orders accept legacy `login` or an `accounts` collection matching the complete trusted account set for the current page. Account ownership is always checked.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| clientRequestId | string | Yes | Idempotency identifier with 1 to 64 printable characters after trimming |
| dataset | string | Yes | POSITION_CURRENT for positions; ORDER_CURRENT for pending orders; Allowed values: `POSITION_CURRENT`, `ORDER_CURRENT` |
| sourceView | string | Yes | SPOT, CONTRACT, PORTFOLIO, or VAULT; positions do not support SPOT; Allowed values: `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| filters | object | Yes | Positions: login, symbol, positionType, direction. Pending orders: accounts or legacy login, symbol, direction |
| sort | object | No | Optional sorting from the allowed fields |
| language | string | No | Language tag normalized by the shared CSV catalog; nullable |
| timeZone | string | Yes | IANA time zone used to display the file |
| csvCatalogVersion | string | No | Frozen column version supported by the dataset; nullable |
| retryOfTaskId | string | No | Original FAILED task for the same owner and list; nullable |

`sort` fields (both are required when sort is provided):

| Field | Type | Description |
| --- | --- | --- |
| field | string | Original sort field allowed by the dataset |
| direction | string | `ASC` / `DESC` |

### Response `data` fields

HTTP `202 Accepted`; The task is generated asynchronously.

| Field | Type | Description |
| --- | --- | --- |
| taskId | string | Opaque unique task identifier |
| dataset | string | Task dataset; Allowed values: `DEAL_HISTORY`, `ORDER_HISTORY`, `FUNDING_FEE_HISTORY`, `POSITION_CURRENT`, `ORDER_CURRENT` |
| language | string | Normalized language code fixed at creation |
| sourceView | string | Original source: SPOT, CONTRACT, or PORTFOLIO; may be empty for older tasks; Allowed values: `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT`; Nullable |
| retryOfTaskId | string | Original task associated with this retry; empty for non-retry tasks; Nullable |
| retryContext | object | Retry conditions are provided only for complete, authorized FAILED tasks that are safe to retry; Nullable |
| status | string | Task status; Allowed values: `QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | Failure reason; populated only when status is FAILED; Allowed values: `GENERATION`, `UPLOAD`, `RESTART`, `TIMEOUT`; Nullable |
| createdAt | integer | Creation time in Unix milliseconds (UTC) |
| updatedAt | integer | Update time in Unix milliseconds (UTC) |
| expiresAt | integer | Absolute expiration time in Unix milliseconds (UTC) |
| rowCount | integer | Exported row count; empty before completion or when the limit is exceeded; Nullable |
| fileName | string | Download file name; populated only for successful tasks; Nullable |
| downloadAvailable | boolean | True when the service confirms the file is complete and unexpired |

`retryContext` fields:

| Field | Type | Description |
| --- | --- | --- |
| originalTaskId | string | Original failed task identifier |
| createRequest | object | Original public creation parameters; excludes ownership context, internal account sets, and the previous idempotency key |

`retryContext.createRequest` fields:

| Field | Type | Description |
| --- | --- | --- |
| `<key>` | object | Original public creation parameters; excludes ownership context, internal account sets, and the previous idempotency key |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "clientRequestId": "current-export-demo-001",
  "dataset": "POSITION_CURRENT",
  "sourceView": "CONTRACT",
  "filters": {
    "login": "10000001",
    "positionType": "SYMBOL"
  },
  "timeZone": "Asia/Shanghai"
}'
```

## Download current-list CSV

`GET /openapi/v1/mc-trade/export-tasks/{taskId}/download` — Permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| taskId | string | Yes | Min length: 1; Max length: 64 |

### Response

HTTP `302 Found`; `Location` contains a temporary download URL; `Cache-Control: no-store`. No JSON `data`.

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-trade/export-tasks/TASK_DEMO_001/download" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
