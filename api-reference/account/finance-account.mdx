## Withdraw from Finance account (flexible)

`POST /openapi/v1/mc-account/finance/account/withdraw` — permission `TRADE`.

Flexible products only: pass the product code and withdrawal amount. Funds move from the Finance account to the fund account, then into spot. For multiple fixed-term positions, use the fixed-term position withdrawal endpoint and specify the position detail ID.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| trackingId | string | No | Unique request tracking ID |
| productCode | string | Yes | Flexible finance product code |
| amount | number | Yes | Withdrawal amount; Minimum: 1e-08 |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| data | string | `data` is a scalar of this type |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-account/finance/account/withdraw" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "trackingId": "finance-withdraw-demo-001",
  "productCode": "USDT_CURRENT",
  "amount": 10
}' 
```

## Finance product catalog

`GET /openapi/v1/mc-account/finance/products/catalog` — permission `READ`.

Returns the full list of enabled product configurations by type (flexible / fixed-term), unpaginated, sorted descending by base APR plus bonus APR. Query parameter `type` is required.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| type | string | Yes | Product type: current or fixed; Allowed values: `CURRENT`, `FIXED` |

### Response `data` fields

`data` is an array of objects. Element fields follow.

`data[]` items:

| Field | Type | Description |
| --- | --- | --- |
| productCode | string | Product Code |
| productName | string | Product name |
| type | string | Type: current or fixed; Allowed values: `CURRENT`, `FIXED` |
| currency | string | Currency |
| annualRate | string | Base APY% |
| rewardAnnualRate | string | Excess reward APY% (config tier) |
| maxAnnualRate | string | Maximum APY% = base + flexible-product excess reward + the signed-in user's highest eligible coupon rate |
| couponSupported | boolean | Whether interest coupons are supported |
| couponNominalAnnualRate | string | Highest available coupon nominal annual rate as a percentage |
| rewardMinHoldingDays | integer | Consecutive holding days required for rewards; empty or 0 for fixed-term products |
| rewardMinPosition | string | Principal threshold for extra rewards; empty or 0 for fixed-term products |
| periodDays | integer | Fixed-term duration in days; 0 for flexible products |
| minDepositAmount | string | Minimum initial deposit |
| minRedeemAmount | string | Minimum redemption amount |
| digit | integer | Currency precision (decimal places) |
| subscribedAmount | string | Net retained subscription principal in the pool: cumulative deposits minus redemptions plus redeemed interest; used for pool-cap checks |
| fundPoolAmount | string | Maximum pool size; null or a value at most 0 means unlimited |
| availableSubscriptionBalance | string | Remaining deposit capacity under the pool cap; null when no cap is configured |
| subscriptionStartTime | string | Subscription window start; no time restriction when both start and end are null |
| subscriptionEndTime | string | Subscription window end; no time restriction when both start and end are null |
| maxDepositAmount | string | Maximum deposit per user; null or a value at most 0 means unlimited |
| dailyMaxRedeemAmount | string | Daily withdrawal limit |
| subscriptionStartTimeTimestamp | string | Subscription window start in Unix milliseconds |
| subscriptionEndTimeTimestamp | string | Subscription window end in Unix milliseconds |

```bash
ACCESS_KEY="${MC_ACCESS_KEY:?Set MC_ACCESS_KEY}"
SECRET_KEY="${MC_SECRET_KEY:?Set MC_SECRET_KEY}"
METHOD="GET"
PATH_="/openapi/v1/mc-account/finance/products/catalog"
TYPE="CURRENT"
CANONICAL_QUERY="type=${TYPE}"
TIMESTAMP=$(python3 -c 'import time; print(int(time.time() * 1000))')
NONCE=$(python3 -c 'import uuid; print(uuid.uuid4())')
SIGNED_HEADERS="x-access-key=${ACCESS_KEY}&x-nonce=${NONCE}&x-timestamp=${TIMESTAMP}"

SIGNATURE=$(
  printf '%s\n%s\n%s\n%s\n%s\n%s\n' \
    "$METHOD" "$PATH_" "$CANONICAL_QUERY" "$SIGNED_HEADERS" "$TIMESTAMP" "$NONCE" \
  | openssl dgst -sha256 -hmac "$SECRET_KEY" -binary \
  | openssl base64 -A
)

curl -sS -G "https://gateway.mcconnects.com${PATH_}" \
  -H "X-Access-Key: ${ACCESS_KEY}" \
  -H "X-Signature: ${SIGNATURE}" \
  -H "X-Timestamp: ${TIMESTAMP}" \
  -H "X-Nonce: ${NONCE}" \
  --data-urlencode "type=${TYPE}"
```

`CANONICAL_QUERY` uses the unencoded logical value `type=CURRENT`; `curl --data-urlencode` only builds the transport URL. Validate your implementation first with the [fixed query signing vector](/authentication#example-2-get-with-query).

## Current Finance account positions

`GET /openapi/v1/mc-account/finance/account/positions/holding` — permission `READ`.

Paginated query of active and matured positions for the context user ID. Multiple flexible positions for the same product are aggregated into one row. Results are sorted by `product_code` ascending, then `currency` ascending. `positionAmount` is total position principal (excludes unsettled interest; see `currentRewardAmount` for interest). `cumulativeRewardAmount` is the historical settled interest total in the original currency for that product and currency, not converted to USDC. Returns an empty page when not logged in or when the business line is missing.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| size | integer | No | Page size |
| current | integer | No | Current page number, starting from 1 |
| orderBy | string | No | Multi-field sort; comma-separated fields |
| orderDirection | string | No | ASC ascending / DESC descending; comma-separated for multiple fields; Allowed values: `ASC`, `DESC` |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| records | array | Records on the current page |
| total | integer | Total number of records |
| size | integer | Page size |
| current | integer | Current page number |
| pages | integer | Total number of pages |
| hasPrevious | boolean | Whether a previous page exists |
| hasNext | boolean | Whether a next page exists |

| Field | Type | Description |

## Finance account overview

`GET /openapi/v1/mc-account/finance/account/overview` — permission `READ`.

Returns `products` by product dimension, ordered by `product_code` ascending, then `currency` ascending. User-side `userDepositedAmount`, `userInterestAmount`, and `availableBalance` come from position aggregates in `ac_user_finance_position` for that product (in the product currency). `totalDepositValue` is the sum of each product's position principal × oracle price, converted to USDC. `totalInterestValue` and `yesterdayInterestValue` are interest settlement records converted to USDC by currency. `userSpotAvailableBalance` is per trading-account currency; products sharing the same currency have the same value. User-side values are 0 when not logged in.

| Field | Type | Description |
| --- | --- | --- |
| totalDepositValue | string | User total deposit (principal per currency × corresponding oracle price, converted to USDC; 0 when not logged in) |

| yesterdayInterestValue | string | Yesterday's interest (settled interest records from the previous calendar day in Asia/Shanghai timezone, converted to USDC using the same oracle; 0 when not logged in) |
| products | array | By product dimension: each entry corresponds to ac_finance_product + configuration. User amounts come from position summaries under that product, platform fields come from product summary tables. Includes subscribedAmount, fundPoolAmount, a |
| totalDepositValueDisplay | string | User total deposit display value |

## Withdraw the full finance balance

`POST /openapi/v1/mc-account/finance/account/withdraw/all` — Permission `TRADE`。

For a current product, provide `productCode` so the server calculates the full redeemable amount. For a fixed position, provide `positionId` to redeem its principal and interest. Provide exactly one of these fields; do not send `amount`. The existing amount-based and fixed-position withdrawal endpoints remain available.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| trackingId | string | No | Unique request tracking ID |
| productCode | string | No | Required for full withdrawal of a current product; mutually exclusive with positionId |
| positionId | integer | No | Required for full withdrawal of a fixed position; mutually exclusive with productCode. Matches positionId in current positions |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| data | string | `data` is a scalar of this type |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-account/finance/account/withdraw/all" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "trackingId": "finance-withdraw-all-demo-001",
  "productCode": "USDT_CURRENT"
}'
```
