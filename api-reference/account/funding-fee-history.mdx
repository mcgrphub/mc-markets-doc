## Paginated funding fee history V2

`GET /openapi/v1/mc-account/funding-fee-record/page/v2` — permission `READ`.

`feeType` is fixed to INTEREST_FEE/FUNDING_FEE; amounts are aggregated by `positionId` + `dealTime`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| size | integer | No | Page size |
| current | integer | No | Current page number, starting from 1 |
| orderBy | string | No | Multi-field sort; comma-separated |
| orderDirection | string | No | ASC ascending / DESC descending; comma-separated for multiple fields |
| userId | string | No | User ID |
| login | string | No | MT5 login ID |
| dealTimeStart | string | No | Fee deduction start time |
| dealTimeEnd | string | No | Fee deduction end time |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| records | array | Records on the current page |
| total | integer | Total number of records |
| size | integer | Page size |
| current | integer | Current page number |
| pages | integer | Total number of pages |
| hasPrevious | boolean | Whether a previous page exists |
| hasNext | boolean | Whether a next page exists |

`records[]` items:

| Field | Type | Description |
| --- | --- | --- |
| relatedBizId | string | Related business ID |
| userId | string | User ID |
| login | string | Trading account login |
| businessLineId | integer | Business line ID |
| businessLineName | string | Business line name |
| dealTime | string | Fee deduction time |
| symbol | string | Settlement currency |
| symbolPair | string | Trading pair |
| amount | number | Aggregated amount; a negative value indicates a deduction |
| remark | string | Remark |
| createTime | string | Record creation time |
| updateTime | string | Record update time |
| feeRate | number | Fee rate |
| volume | number | Position volume |
| positionSide | string | Position side |
| positionId | string | Position ID |
| batchTime | string | Fee settlement batch time |
| amountDisplay | string | Funding-fee amount display value |
| amountScale | integer | Funding-fee amount display precision |
| createTimeTimestamp | integer | Creation time in Unix milliseconds |
| updateTimeTimestamp | integer | Update time in Unix milliseconds |
| dealTimeTimestamp | integer | Fee deduction time in Unix milliseconds |
| feeRateDisplay | string | Funding-rate percentage display value |
| feeRateScale | integer | Funding-rate display precision |
| batchTimeTimestamp | integer | Settlement batch time in Unix milliseconds |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/page/v2" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "size=1" \
  --data-urlencode "current=1"
```
