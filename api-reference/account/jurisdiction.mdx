## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-account/jurisdiction/access-result | Public | Check access region |
| GET | /openapi/v1/mc-account/jurisdiction/evaluation | READ | Evaluate jurisdiction checks |

<Note>
Sign authenticated requests with AK/SK as described in [Authentication](/authentication). Public endpoints require no signature. See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

## Check access region

`GET /openapi/v1/mc-account/jurisdiction/access-result` — permission `Public`.

Available anonymously or when signed in; the result does not authorize business writes


### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| result | string | Access result; Allowed values: `ACCESS_ALLOWED`, `JURISDICTION_RESTRICTED`, `JURISDICTION_UNKNOWN` |
| messageKey | string | Message key; an empty string when access is allowed |
| policyVersion | string | Opaque policy version |
| evaluatedAtMillis | integer | Evaluation completion time in Unix milliseconds (UTC) |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/jurisdiction/access-result"
```

## Evaluate jurisdiction checks

`GET /openapi/v1/mc-account/jurisdiction/evaluation` — permission `READ`.

Read-only preflight check; the final write request is evaluated again

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| action | string | No |  |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| decision | string | Access decision; Allowed values: `PASS`, `KYC_REQUIRED`, `JURISDICTION_RESTRICTED`, `JURISDICTION_UNKNOWN` |
| reasonSource | string | Decision source; the specific country is not returned; Allowed values: `NONE`, `ACCESS_COUNTRY`, `IDENTITY_COUNTRY`, `BASIC_KYC` |
| policyVersion | string | Opaque policy version |
| evaluatedAtMillis | integer | Evaluation completion time in Unix milliseconds (UTC) |
| retryable | boolean | Whether the client may retry after the underlying facts change |
| messageKey | string | Message key; an empty string when the check passes |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/jurisdiction/evaluation" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
