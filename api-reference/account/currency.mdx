Paths in this group use the `/openapi/v1/mc-account/` prefix.

## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-account/symbol/list | READ | Query symbol network list |
| GET | /openapi/v1/mc-account/symbol/exchange/list | READ | Query exchangeable symbol list |

<Note>
  The interactive Playground is disabled. Sign requests with AK/SK as described in [Authentication](/authentication). See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

## Query symbol network list

`GET /openapi/v1/mc-account/symbol/list` — permission `READ`.


### Response `data` fields

`data` is an array of objects. Element fields follow.

`data[]` items:

| Field | Type | Description |
| --- | --- | --- |
| symbolId | string | Currency identifier |
| assetType | string | Currency type; Allowed values: `CRYPTO`, `FIAT` |
| symbol | string | Currency Name |
| network | string | Currency Network Protocol |
| minTradeUnit | string | Minimum Transfer Unit |
| pricePrecision | integer | Price digits |
| exchangeRate | string | Exchange Rate |
| subscriptionCurrencyPair | string | Subscribed market-data pair, such as ETHUSD.c; null without a subscription |
| minRechargeAmount | string | Minimum Deposit Amount |
| minWithdrawAmount | string | Minimum Withdrawal Amount |
| assetNet | string | Asset Network |
| iconData | string | Network Protocol Icon |
| depositStatus | integer | Whether deposit is available, [0: No, 1: Yes] |
| withdrawalStatus | integer | Whether withdrawal is available, [0: No, 1: Yes] |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-account/symbol/list" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
