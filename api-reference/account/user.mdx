## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| GET | /openapi/v1/mc-account/user-v2/profile | READ | Query the authenticated user's profile |

<Note>
  The interactive Playground is disabled. Sign requests with AK/SK as described in [Authentication](/authentication). See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

<Warning>
  The response may contain sensitive personal data, including email, phone, address, and identity-document details. Limit where this data is logged, stored, or forwarded. The `uid` must match the authenticated user; this endpoint cannot query another user.
</Warning>

## Query the authenticated user's profile

`GET /openapi/v1/mc-account/user-v2/profile` — permission `READ`.

Returns core user details, profile data, Privy authentication methods, legacy-compatible invitation and KYC information, and spot and contract trading-account readiness.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| uid | string | Yes |  |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| user | object | Core user details |
| authList | array | Authentication methods bound through Privy |
| profile | object | Extended user profile |
| legacy | object | Legacy-compatible additional user details, including invitations, KYC, and subaccounts |
| boundLoginMethods | array | Bound Privy login methods: email, google, or wallet, in lowercase |
| currentLoginMethod | string | Current session login method: email, google, or wallet. May be null for OpenAPI stateless JWT sessions when the service cannot resolve it; supplied by the client or gateway |
| allTradingAccountsReady | boolean | Whether both spot and trading logins have been generated; may temporarily be false during asynchronous registration |

`user` fields:

| Field | Type | Description |
| --- | --- | --- |
| uid | string | User UID |
| email | string | Email address |
| walletAddress | string | Wallet address bound as a login credential |
| spotAccount | string | Spot trading account |
| tradeAccount | string | Contract trading account |
| demoAccount | string | Demo account |
| registerType | integer | Registration source |
| appId | string | Channel ID |
| clientId | string | Device ID |
| version | string | Client version |
| ip | string | Registration IP address |
| ipAddr | string | IP geolocation |
| imRef | string | IM_REF promotion parameter |

`authList[]` items:

| Field | Type | Description |
| --- | --- | --- |
| authType | string | Authentication type |
| privyType | integer | Third-party type |

`profile` fields:

| Field | Type | Description |
| --- | --- | --- |
| nickname | string | Nickname |
| avatar | string | Avatar URL |
| phone | string | Phone number |
| mobileAreaId | integer | Calling code |
| country | string | Country |
| address | string | Address |
| gender | integer | Gender: 0 unknown, 1 male, 2 female |
| birthday | string | Date of birth, yyyy-MM-dd |

`legacy` fields:

| Field | Type | Description |
| --- | --- | --- |
| uid | string | User UID as a string, corresponding to legacy UserId |
| email | string | Email address in plain text; legacy storage may be encrypted |
| countryId | integer | Country or region ID parsed from profile.country when numeric; otherwise 0 |
| mobileAreaId | integer | Phone area code from the user profile, with the fund-account country code as fallback |
| mobile | string | Phone number associated with the fund account |
| credentialsType | integer | Document type: 0 none, 1 identity card, 2 passport, 3 driving license, 99 other |
| credentialsNum | string | KYC document number |
| credentialsCountryId | integer | Document-issuing country or region ID when the source value is numeric |
| credentialsValidDateEnd | string | KYC document validity end |
| isLongTime | boolean | Whether the document has indefinite validity, determined from its validity end value |
| cardStatus | integer | Document or KYC status: 0 no record, 1 pending, 2 approved, 3 rejected, 4 not submitted |
| noCard | string | Notes concerning missing documents; an empty string when no dedicated field exists |
| createTime | string | User creation time, yyyy-MM-dd HH:mm:ss |
| spreadCode | string | Your referral or invitation code (SpreadCode) |
| disseminatorCode | string | Referrer invitation code supplied at registration (DisseminatorCode) |
| recommendedTime | string | Referral or invitation binding time, yyyy-MM-dd HH:mm:ss |
| nickName | string | Nickname, consistent with profile and repeated at the top level for older clients |
| avatar | string | Avatar, consistent with profile |
| userLanguage | string | User language preference; null before synchronization |
| appId | string | Channel AppId |
| cardSubmitTime | string | KYC submission time, yyyy-MM-dd HH:mm:ss |
| accountInfos | array | Subaccount and trading-login list, compatible with legacy AccountInfos |
| createTimeTimestamp | string | User creation timestamp in milliseconds |
| recommendedTimeTimestamp | string | Referral or invitation binding time in Unix milliseconds |
| cardSubmitTimeTimestamp | string | KYC submission timestamp in milliseconds |

`legacy.accountInfos[]` items:

| Field | Type | Description |
| --- | --- | --- |
| account | string | Trading login or subaccount number (MT5 Account) |
| accountType | integer | Account type: 1 real, 2 demo |
| accountGroup | integer | Account group: 1 trading, 2 spot |
| createTime | string | Creation time, yyyy-MM-dd HH:mm:ss; uses the user creation time when no separate record exists |
| createTimeTimestamp | string | Creation timestamp in milliseconds |

```bash
curl -sS -G "https://gateway.mcconnects.com/openapi/v1/mc-account/user-v2/profile" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  --data-urlencode "uid=YOUR_UID"
```
