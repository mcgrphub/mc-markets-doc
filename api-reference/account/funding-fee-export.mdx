## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| GET | `/openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}` | READ | Get a funding fee export task |
| GET | `/openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}/download` | READ | Download funding fee history CSV |
| POST | /openapi/v1/mc-account/funding-fee-record/export-tasks | READ | Create a funding fee export task |

<Note>
Sign authenticated requests with AK/SK as described in [Authentication](/authentication). Public endpoints require no signature. See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

This creation endpoint only exports funding fee history and uses `FUNDING_FEE_HISTORY`. The task response is shared; other `dataset` enum values do not enable this endpoint to create other datasets. For funding fee tasks, `retryOfTaskId` is `null`. `retryContext` contains the original frozen conditions only when retry is available; otherwise it is `null`.

## Get a funding fee export task

`GET /openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}` — permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| taskId | string | Yes |  |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| taskId | string | Task ID |
| sourceView | string | Original source: SWAP, SPOT, CONTRACT, or PORTFOLIO; null for legacy tasks with an unknown source; Allowed values: `SWAP`, `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| retryOfTaskId | string | Original failed task ID associated with this task; null for funding fee and ordinary task creation |
| retryContext | object | Original frozen conditions for retry; explicitly null when retry is unavailable |
| dataset | string | FUNDING_FEE_HISTORY, SWAP_HISTORY, BALANCE, FUND_FLOW, or DEPOSIT_WITHDRAW; Allowed values: `FUNDING_FEE_HISTORY`, `SWAP_HISTORY`, `BALANCE`, `FUND_FLOW`, `DEPOSIT_WITHDRAW` |
| language | string | Normalized CSV language |
| status | string | QUEUED、RUNNING、SUCCEEDED、EMPTY、OVER_LIMIT、FAILED; Allowed values: `QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | GENERATION, UPLOAD, RESTART, or TIMEOUT for failed tasks; otherwise null; Allowed values: `RESTART`, `GENERATION`, `UPLOAD`, `TIMEOUT` |
| createdAt | string | Creation time in Unix milliseconds (UTC) |
| updatedAt | string | Update time in Unix milliseconds (UTC) |
| expiresAt | string | Expiration time in Unix milliseconds (UTC) |
| rowCount | integer | Data rows excluding the header; null before generation or when the limit is exceeded |
| fileName | string | Downloadable file name; nullable |
| downloadAvailable | boolean | True only after success, before expiration, and after file metadata verification |

`retryContext` fields:

| Field | Type | Description |
| --- | --- | --- |
| originalTaskId | string | Current failed task ID |
| createRequest | object | Fields accepted by the original creation endpoint, excluding clientRequestId |

`retryContext.createRequest` fields:

| Field | Type | Description |
| --- | --- | --- |
| `<key>` | object | Fields accepted by the original creation endpoint, excluding clientRequestId |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/export-tasks/TASK_DEMO_001" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## Download funding fee history CSV

`GET /openapi/v1/mc-account/funding-fee-record/export-tasks/{taskId}/download` — permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| taskId | string | Yes |  |

### Response

HTTP `302 Found`; `Location` contains a temporary download URL; `Cache-Control: no-store`. No JSON `data`.

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/funding-fee-record/export-tasks/TASK_DEMO_001/download" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

## Create a funding fee export task

`POST /openapi/v1/mc-account/funding-fee-record/export-tasks` — permission `READ`.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| clientRequestId | string | Yes | Min length: 0; Max length: 64 |
| from | integer | Yes |  |
| to | integer | Yes |  |
| sort | string | Yes | Allowed values: `DEAL_TIME_DESC` |
| sourceView | string | No | Optional source: SPOT, CONTRACT, or PORTFOLIO; null preserves the legacy unknown-source behavior; Allowed values: `SWAP`, `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| language | string | No |  |
| timeZone | string | Yes |  |

### Response `data` fields

HTTP `202 Accepted`; The task is generated asynchronously.

| Field | Type | Description |
| --- | --- | --- |
| taskId | string | Task ID |
| sourceView | string | Original source: SWAP, SPOT, CONTRACT, or PORTFOLIO; null for legacy tasks with an unknown source; Allowed values: `SWAP`, `SPOT`, `CONTRACT`, `PORTFOLIO`, `VAULT` |
| retryOfTaskId | string | Original failed task ID associated with this task; null for funding fee and ordinary task creation |
| retryContext | object | Original frozen conditions for retry; explicitly null when retry is unavailable |
| dataset | string | FUNDING_FEE_HISTORY, SWAP_HISTORY, BALANCE, FUND_FLOW, or DEPOSIT_WITHDRAW; Allowed values: `FUNDING_FEE_HISTORY`, `SWAP_HISTORY`, `BALANCE`, `FUND_FLOW`, `DEPOSIT_WITHDRAW` |
| language | string | Normalized CSV language |
| status | string | QUEUED、RUNNING、SUCCEEDED、EMPTY、OVER_LIMIT、FAILED; Allowed values: `QUEUED`, `RUNNING`, `SUCCEEDED`, `EMPTY`, `OVER_LIMIT`, `FAILED` |
| failureReason | string | GENERATION, UPLOAD, RESTART, or TIMEOUT for failed tasks; otherwise null; Allowed values: `RESTART`, `GENERATION`, `UPLOAD`, `TIMEOUT` |
| createdAt | string | Creation time in Unix milliseconds (UTC) |
| updatedAt | string | Update time in Unix milliseconds (UTC) |
| expiresAt | string | Expiration time in Unix milliseconds (UTC) |
| rowCount | integer | Data rows excluding the header; null before generation or when the limit is exceeded |
| fileName | string | Downloadable file name; nullable |
| downloadAvailable | boolean | True only after success, before expiration, and after file metadata verification |

`retryContext` fields:

| Field | Type | Description |
