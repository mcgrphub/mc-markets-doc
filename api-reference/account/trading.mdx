Paths in this group use the `/openapi/v1/mc-account/` prefix.

## Endpoints

| Method | Path | Permission | Description |
| --- | --- | --- | --- |
| POST | /openapi/v1/mc-account/transaction/transaction/record/page | READ | Paginate transaction records |
| POST | /openapi/v1/mc-account/transaction/exchange/v2 | TRADE | Flash conversion (quote-supported) |
| POST | /openapi/v1/mc-account/transaction/account/record/page | READ | Paginate fund account ledger records |
| GET | `/openapi/v1/mc-account/transaction/user-transfer/recipients/{recipientUid}/validation` | READ | Validate a transfer recipient |


<Note>
  The interactive Playground is disabled. Sign requests with AK/SK as described in [Authentication](/authentication). See [Base URL](/api-reference/base-url) for the gateway host.
</Note>

<Info>
  Transaction filter enums: `transactionMethod` accepts `CHAIN_TX`, `USER_TRANSFER`, or `OTHER`. `transactionType` accepts `RECHARGE`, `WITHDRAWAL`, `TRANSFER_IN`, `TRANSFER_OUT`, `EXCHANGE`, `SAFEBOX_TRANSFER_IN`, `SAFEBOX_TRANSFER_OUT`, `ROLLBACK`, `ADJUSTMENT_ADD`, `ADJUSTMENT_REDUCE`, `MLP_DEPOSIT`, `MLP_WITHDRAWAL`, `TRANSFER_TRADE_TO_SPOT`, `TRANSFER_SPOT_TO_TRADE`, `EARN_DEPOSIT`, `EARN_WITHDRAWAL`, `PROMO_REWARD_IN`, or `PROMO_REWARD_OUT`.
</Info>

## Flash conversion (quote-supported)

`POST /openapi/v1/mc-account/transaction/exchange/v2` — permission `TRADE`.

Complete a flash conversion. First call [Query flash conversion exchange rate](/api-reference/account/exchange-rate#query-flash-conversion-exchange-rate) to get a valid `quoteSessionId`.

### Request body (JSON)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| trackingId | string | No | Unique request tracking ID |
| symbol | string | Yes | e.g. BTC/USDT |
| exchangeSymbol | string | Yes | e.g. BTC/USDT |
| amount | number | Yes | Exchange amount / quantity of the exchange symbol; Minimum: 1e-08 |
| quoteSessionId | string | Yes | Quote session ID from the flash conversion rate quote |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| data | string | `data` is a scalar of this type |

```bash
curl -sS -X POST "https://gateway.mcconnects.com/openapi/v1/mc-account/transaction/exchange/v2" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE" \
  -H "Content-Type: application/json" \
  -d '{
  "trackingId": "exchange-demo-001",
  "symbol": "BTC",
  "exchangeSymbol": "USDT",
  "amount": 0.01,
  "quoteSessionId": "QUOTE_DEMO_001"
}' 
```

## Validate a transfer recipient

`GET /openapi/v1/mc-account/transaction/user-transfer/recipients/{recipientUid}/validation` — Permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| recipientUid | string | Yes |  |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| valid | boolean | True only when reason is NONE |
| reason | string | NONE: can receive; NOT_FOUND: not visible; NOT_RECEIVABLE: cannot receive; SELF: the current user; Allowed values: `NONE`, `NOT_FOUND`, `NOT_RECEIVABLE`, `SELF` |
| checkedAtTimestamp | string | Server time when validation completed, in Unix milliseconds (UTC) |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/transaction/user-transfer/recipients/100000001/validation" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
