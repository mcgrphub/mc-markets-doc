## List user vaults

`GET /openapi/v1/mc-account/user-vaults` — permission `READ`.

### Query / path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| keyword | string | No |  |
| sort | string | No |  |
| current | integer | No |  |
| size | integer | No |  |
| include | string | No | Optional expansion: sparkline returns the NAV sparkline for the last 30 days |

### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| records | array | Records on the current page |
| total | integer | Total number of records |
| size | integer | Page size |
| current | integer | Current page number |
| pages | integer | Total number of pages |
| hasPrevious | boolean | Whether a previous page exists |
| hasNext | boolean | Whether a next page exists |

`records[]` items:

| Field | Type | Description |
| --- | --- | --- |
| vaultId | string | Public vault identifier |
| name | string | Vault name |
| strategySummary | string | Strategy summary; returned in both listings and details |
| status | string | Status enum; independent of frozen |
| frozen | boolean | Operational freeze flag; independent of status |
| navPerShare | number | Latest published NAV per share; null before publication |
| aum | number | AUM after fees |
| totalShares | number | Issued shares, with 8 decimal places; excludes unconfirmed subscriptions |
| maxAumCap | number | AUM cap = seed × 20; fixed at creation |
| capacityRatio | number | Capacity ratio = aum / maxAumCap; null if the cap is invalid |
| myShares | number | Your confirmed shares in this pool; 0 with no holding; omitted when no user context is available |
| sparkline | array | NAV sparkline for the last 30 days; returned only with include=sparkline; null or empty when no published points exist |
| ownerShareRatio | number | Manager ownership ratio = manager confirmed shares / total confirmed shares; null when no shares exist |
| investedUserCount | integer | Number of depositors holding confirmed shares, including the manager |
| accruedPerformanceFee | number | Cumulative crystallized performance fees for this pool in USDC; collectedPerformanceFee |
| collectedPerformanceFee | number | Crystallized performance fees collected in USDC; equals accruedPerformanceFee; prefer this field |
| performanceFeeRate | number | Performance fee rate in [0, 0.30] |
| minSubscription | number | Minimum subscription in USDC |
| maxSubscription | number | Maximum subscription in USDC |
| lastNavAt | integer | Latest NAV publication time in Unix milliseconds (UTC) |
| createdAt | integer | Creation time in Unix milliseconds (UTC) |
| return30d | number | 30-day return; null when fewer than two published points exist |
| ownerUid | string | Creator UID; omitted from the market listing |
| mt5Login | integer | Vault contract MT5 login; omitted from the market listing |

`records[].sparkline[]` items:

| Field | Type | Description |
| --- | --- | --- |
| asOf | integer | Valuation time in Unix milliseconds (UTC) |
| navPerShare | number | NAV per share |
| aum | number | Total NAV after fees |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/user-vaults" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```

| --- | --- | --- | --- |
| clientOrderId | string | Yes | Client idempotency identifier; at most 64 characters; Min length: 1; Max length: 64 |

| maxAumCap | number | AUM cap = seed × 20 |
