## Get KYC base profile data

`GET /openapi/v1/mc-account/kyc/profile/base` — permission `READ`.

Query KYC base profile data for the current authenticated user in the current business line. The authenticated context determines the user identity; the endpoint does not accept a UID query parameter.


### Response `data` fields

| Field | Type | Description |
| --- | --- | --- |
| applyNo | string | Current business-line KYC application ID; null when none exists |
| businessLineId | string | Business line ID |
| l0StepPassed | boolean | Whether the basic verification (L0) step has passed review; modification is allowed only when true |
| firstName | string | First name |
| lastName | string | Last name |
| nationality | string | Nationality |
| residenceCountry | string | Country of residence |
| residenceRegion | string | Region of residence |
| birthDate | string | Date of birth |
| kycType | string | Identity document type; Allowed values: `ID_CARD`, `PASSPORT`, `DRIVER_LICENSE`, `OTHER` |
| certNo | string | Identity document number |
| certValidUntil | string | Document validity end, yyyy-MM-dd |
| certValidFrom | string | Document validity start, yyyy-MM-dd |
| certPermanentFlag | integer | Whether the document is permanent: `1` yes, `0` no |
| certIssueRegion | string | Issuing region |

```bash
curl -sS "https://gateway.mcconnects.com/openapi/v1/mc-account/kyc/profile/base" \
  -H "X-Access-Key: YOUR_ACCESS_KEY" \
  -H "X-Signature: YOUR_SIGNATURE" \
  -H "X-Timestamp: YOUR_TIMESTAMP" \
  -H "X-Nonce: YOUR_NONCE"
```
