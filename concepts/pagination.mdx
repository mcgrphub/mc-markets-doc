Most MC OpenAPI list endpoints use `current` and `size`; records are returned in `data.records`. Check each endpoint page for parameter placement and optional filters.

<Note>
  Market ranking endpoints use a different shape: request `page` / `pageSize` and read the list from `data.items`. Do not mix fields between these pagination formats.
</Note>

## Request parameters

Regular paginated endpoints accept these fields in the GET query or POST JSON body:

<ParamField query="current" default="1" type="integer">
  Current page number, starting from 1.
</ParamField>

<ParamField query="size" type="integer">
  Number of records per page. Check the endpoint schema for limits and defaults.
</ParamField>

## Response shape

The regular pagination object is under `data`:

```json
{
  "status": 200,
  "message": "ok",
  "code": "200",
  "codeKey": null,
  "params": {},
  "localizedMessage": null,
  "success": true,
  "data": {
    "records": [
      {
        "transactionId": "T-1001",
        "amount": 125.5,
        "acSymbol": "USDT",
        "createTimeTimestamp": 1731657600000
      }
    ],
    "total": 132,
    "size": 20,
    "current": 1,
    "pages": 7,
    "hasPrevious": false,
    "hasNext": true
  }
}
```

Prefer `hasNext` when advancing pages. If an endpoint omits it, use `current < pages`.

## Python: iterate over transaction records

This example calls `POST /openapi/v1/mc-account/transaction/transaction/record/page`. It generates a new timestamp and nonce for every page and signs the exact body bytes that it sends.

```python
import base64
import hashlib
import hmac
import json
import os
import time
import uuid

import requests

BASE_URL = "https://gateway.mcconnects.com"
ACCESS_KEY = os.environ["MC_ACCESS_KEY"]
SECRET_KEY = os.environ["MC_SECRET_KEY"]


def signed_headers(method: str, path: str, body: bytes) -> dict[str, str]:
    timestamp = str(int(time.time() * 1000))
    nonce = str(uuid.uuid4())
    canonical_headers = (
        f"x-access-key={ACCESS_KEY}&x-nonce={nonce}&x-timestamp={timestamp}"
    )
    body_hash = hashlib.sha256(body).hexdigest()
    string_to_sign = "\n".join(
        [method, path, canonical_headers, timestamp, nonce, body_hash]
    ) + "\n"
    signature = base64.b64encode(
        hmac.new(
            SECRET_KEY.encode(), string_to_sign.encode(), hashlib.sha256
        ).digest()
    ).decode()
    return {
        "X-Access-Key": ACCESS_KEY,
        "X-Signature": signature,
        "X-Timestamp": timestamp,
        "X-Nonce": nonce,
        "Content-Type": "application/json",
    }


def fetch_all_transactions(page_size: int = 20) -> list[dict]:
    path = "/openapi/v1/mc-account/transaction/transaction/record/page"
    current = 1
    items = []

    while True:
        body = json.dumps(
            {"current": current, "size": page_size},
            separators=(",", ":"),
        ).encode()
        response = requests.post(
            BASE_URL + path,
            headers=signed_headers("POST", path, body),
            data=body,
            timeout=15,
        )
        response.raise_for_status()
        page = response.json()["data"]
        items.extend(page["records"])
        if not page.get("hasNext", current < page["pages"]):
            return items
        current += 1
```

See [Authentication](/authentication) for the complete signing rules, GET query sorting, and fixed test vectors.

<Tip>
  Use a page size appropriate for your workload, and apply exponential backoff with jitter to `429` and transient `5xx` responses.
</Tip>
