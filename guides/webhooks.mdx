<Note>
  The current public Specs do not expose a webhook or event-stream endpoint. Poll the relevant query endpoint when you need to detect new activity.
</Note>

## Pollable endpoints

The intervals below are client-side starting recommendations, not backend SLAs or fixed limits. Adjust them for your latency needs, payload size, and observed `429` responses.

| What to detect | Endpoint | Suggested starting interval |
| --- | --- | --- |
| New transaction records | `POST /openapi/v1/mc-account/transaction/transaction/record/page` | 30–60 seconds |
| Finance account changes | `GET /openapi/v1/mc-account/finance/account/overview` | 60 seconds |
| Spot position changes | `GET /openapi/v1/mc-account/fund/account/spot-account/positions?spotId=...` | 60–300 seconds |
| Funding-fee records | `GET /openapi/v1/mc-account/funding-fee-record/page/v2` | 300 seconds |
| USD exchange-rate updates | `GET /openapi/v1/mc-account/exchange-rate/query/usd` | 60–300 seconds |

## Watermarks and deduplication

1. Store the greatest processed `createTimeTimestamp` and use `transactionId` as an idempotency key.
2. Set `createTimeStartTimestamp` to that watermark on the next poll.
3. Traverse `data.records` with `current` / `size` until `hasNext` is `false`.
4. Persist business processing before advancing the watermark.
5. Time boundaries can return duplicates, so deduplicate by business ID.

## Python example

```python
import base64
import hashlib
import hmac
import json
import os
import time
import uuid

import requests

BASE_URL = "https://gateway.mcconnects.com"
ACCESS_KEY = os.environ["MC_ACCESS_KEY"]
SECRET_KEY = os.environ["MC_SECRET_KEY"]


def signed_headers(path: str, body: bytes) -> dict[str, str]:
    timestamp = str(int(time.time() * 1000))
    nonce = str(uuid.uuid4())
    canonical_headers = (
        f"x-access-key={ACCESS_KEY}&x-nonce={nonce}&x-timestamp={timestamp}"
    )
    body_hash = hashlib.sha256(body).hexdigest()
    string_to_sign = "\n".join(
        ["POST", path, canonical_headers, timestamp, nonce, body_hash]
    ) + "\n"
    signature = base64.b64encode(
        hmac.new(
            SECRET_KEY.encode(), string_to_sign.encode(), hashlib.sha256
        ).digest()
    ).decode()
    return {
        "X-Access-Key": ACCESS_KEY,
        "X-Signature": signature,
        "X-Timestamp": timestamp,
        "X-Nonce": nonce,
        "Content-Type": "application/json",
    }


def poll_transactions(watermark_ms: int, page_size: int = 20) -> tuple[list[dict], int]:
    path = "/openapi/v1/mc-account/transaction/transaction/record/page"
    current = 1
    records = []
    next_watermark = watermark_ms

    while True:
        body = json.dumps(
            {
                "current": current,
                "size": page_size,
                "createTimeStartTimestamp": watermark_ms,
            },
            separators=(",", ":"),
        ).encode()
        response = requests.post(
            BASE_URL + path,
            headers=signed_headers(path, body),
            data=body,
            timeout=15,
        )
        response.raise_for_status()
        page = response.json()["data"]

        for record in page["records"]:
            records.append(record)
            next_watermark = max(
                next_watermark,
                record.get("createTimeTimestamp", watermark_ms),
            )

        if not page.get("hasNext", current < page["pages"]):
            return records, next_watermark
        current += 1
```

See [Authentication](/authentication) for the complete signing rules and [Pagination](/concepts/pagination) for pagination shapes.

## Operational guidance

- Add random jitter to polling intervals so multiple instances do not request simultaneously.
- Apply exponential backoff with jitter to HTTP `429` and transient `5xx` responses.
- Do not write Secret Keys, watermarks, or account data from responses to public logs.
- Use the real `spotId` when querying spot positions; do not pass a UID as that parameter.
