## 2026-11-05

- Added full finance withdrawal for a current product or fixed position, requiring `TRADE` permission.
- Documented funding fee export source views, task retry context, and file availability while preserving `202` for task creation and `302` for downloads.

## 2026-11-02

- Documented 38 additional public endpoints for user vaults, vault records, negative balance accounts, jurisdiction checks, and CSV exports.
- Updated finance, trading, and market-data response fields, bilingual navigation, and request examples.
- Clarified `202 Accepted` for asynchronous exports, `302` download redirects, and direct CSV responses.
